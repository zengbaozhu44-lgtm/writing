# Story Route V1 P0 — 实验基线冻结

**状态**：`P0-EXPERIMENT-BASELINE-FROZEN` · **更新**：2026-08-30  
**阶段**：**受控实验**（已从「开发一个功能」转出）· **变量不动，继续取样** · 不增加设计层  

---

## 冻结声明

**P0 实验基线已冻结。** 后续新样本：**同一 Reality 投影 · 同一 Route 管线 · 七行最小记录 · 人工判读**。

### 主动不引入（冻结清单）

- 新字段
- 新评分
- Prompt tuning
- Hard Filter 扩张
- `trajectory_subject`
- P1 / orchestrator 接入
- 为提高 A-strict 而修改判定标准

### 新样本只回答两个研究问题

**① 显影结构是否跨案例重复出现？**

> 已存在条件 → 隐性结构应力 → 尚未发生的开放人生方向

**② B2 是否开始稳定聚类？**

> Reality 明明足够，但 Route 仍然只能复述 / 重排已知事实

### 锚点（持续对照）

- **C04** — 负锚（不编剧 ≠ 会发现）
- **C07** — 正边界（Trajectory 作观察方向，非事件生成器）

### 终审纪律（最重要）

> **宁可证明 Route 目前不会发现，也不要通过修改实验让它看起来会发现。**

（同义）宁可让 Route 暴露能力不足，也不要替 Route 证明它有能力。

第三轮结束后，无论结论指向 **「Route 是显影层」** 还是 **「Reality 表达能力才是瓶颈」**，均优于继续 tuning LLM prompt。

## 纯取样阶段（现行）

**已进入。** 新一批结果默认：

- 不重新讨论已冻结 Contract
- 不建议为结果修改 Prompt、字段或规则
- 不把单案表现上升为架构结论
- 严格区分 **A-strict / A-weak / B1 / B2 / B4 / C**
- 最终只从**跨案例重复模式**判断 Route 的真实能力

### 双向_guard（须同时守住）

> **好结果不能自动证明 Route 有能力。**
> **坏结果也不能自动证明 Route 设计有问题。**

只有样本自己形成稳定模式，才值得进入下一阶段的架构判断。

---

**核心边界（InkOS / Story Route 共用）**：

> **系统没有生成未来的资格，只有从真实过去中打开可能性的资格。**

**判定边界（锁死）**：

> **不优化 Route，不追 A 率，只观察它在固定输入边界下究竟暴露出什么能力。**

**判定**：P0 继续 · P1 不接 · Contract 冻结 · Hard Filter 不扩 · `trajectory_subject` 不加

## 一句话（当前验证对象）

> **Story Route V1 现在验证的不是「能不能生成好路线」，而是：在没有未来污染、没有计划注入、没有评分器诱导的前提下，Reality 本身是否已经包含足够的信息，使模型能够发现尚未显性化的人生可能。**

---

## 核心研究问题（比 4/10 更重要）

> **Route 到底是在「发现」人生，还是只是在高质量 Reality 上把已经存在、但尚未显性的结构「显影」出来？**

两个解释**必须靠后续样本区分**，不靠概念争论。

### 实验原则（冻结）

> **Route 不负责创造缺失的信息。**

它最多做三件事：

1. 从 Reality 中找到尚未被显性命名的**结构应力**；
2. 将这些应力展开成若干**开放的人生方向**；
3. 保留足够开放空间，让真正的 Choice 在未来行动中发生。

### 什么不是 Route 失败

| 现象 | 判读 |
|------|------|
| Reality 很薄 → Route 很平庸 | **可能是系统边界正确**（B1），不是 Route 失败 |

### 什么才构成对 `Reality → Possibility` 的反证

| 现象 | 判读 |
|------|------|
| Reality 足够丰富 → Route 仍持续 C04 式复述 | 显影能力不足（B2 / C） |
| Reality 足够丰富 → Route 无法找到任何尚未显性的结构可能 | 核心能力缺口 |

### 本阶段纪律

> **不要优化 Route，让 Route 暴露自己。**

禁止：prompt tuning · 评分器 · 新字段 · P1 · 为提高 A-strict 而修改定义。

继续让**同一系统**面对新的干净 Reality。

### 最终要回答的问题

> **当 Reality 已经真实、充分，而且包含人物尚未显性化的结构张力时，Route 是否能够稳定地把这种张力显影成开放的人生可能？**

（不是：「Route 能不能生成好路线？」）

### 两种答案的架构含义

| 答案 | 含义 |
|------|------|
| **是** | Route = **Reality → Possibility 的显影层**；不是第二个 Planner，不是剧情发动机 |
| **否** | 回头检查 **Reality 的表达能力**；不本能地给 Route 加推理能力 |

### 易犯误判（须避免）

**A-strict 增加 ≠ Route 变强。**

仅当 A-strict 的结构在不同案例中**独立复现**，且**非**靠 prompt 指令、字段或规则得到，才具有研究意义。

### 「开放方向」不因好听而给 A（隐性边界）

> **开放方向不能因为它听起来深刻而被判 A。**

越漂亮、越哲学、越像文学作品的 Route，越要问：

**它到底从 Reality 中哪几个具体条件长出来？**

答不出 → **宁可降 B**，不为证明 Route 有价值而给 A。

### B/C 出现时不急着修

大量 B/C 是正常实验输出。真正有诊断价值的是：

| 类型 | 诊断含义 |
|------|----------|
| **B1** | Reality 本身薄 → **不归罪 Route** |
| **B2** | Reality 足够却只能复述 → 开始怀疑**显影机制** |
| **C04 型** | 干净、合法、不编剧，但没打开可能性 → **最重要负锚** |
| **A-strict** | 仅当跨案例重复「条件 → 隐性应力 → 开放方向」→ 才算能力证据 |

### 最干净的实验状态

```text
Reality 固定 → Route 固定 → 样本增加 → 人工判读 → 等模式自己出现
```

**不用再加任何东西。**

第三轮及以后真正值得看的：

- 是否出现**跨案例重复的显影结构**（非 A 个数）
- **B2** 是否从偶发变为**稳定现象**

## R3 观察目标（非 KPI）

**不要把 4/10 当 KPI。**

若 4 → 6 → 8 但 A 靠更强 prompt 引导，**实验失败**。

真正观察：

1. **B1 / B2 / B4 是否出现稳定聚类**（不可混谈，见 `ANCHORS.md`）
2. **A-strict 共享什么结构**（见下）

### A-strict 共享结构（R2 样本 n=4，假设性归纳）

六条件须**同时**出现（看复现，不看比例）：

| 条件 | 含义 |
|------|------|
| 无新增事实 | Route 不发明 confirmed 之外的事件/关系 |
| 无预设 Choice | 不替人物做决定 |
| 无命运断言 | 不断言「将会如何」为既定结局 |
| 有现实中的结构张力 | 张力来自已有处境，非新冲突制造 |
| 打开未来可能空间 | ≥2 合理展开，非单线剧情 |
| 不是过去事实的换写 | 三问② 不成立 |

若不同案例反复同时满足，「发现人生」开始有**非偶然**证据。

| 条件 | C01 | C02 | C03 | C05 |
|------|-----|-----|-----|-----|
| 六条件同时 | ✓ | ✓ | ✓ | ✓ |

**展开形态**：多为**姿态 / 注意力 / 关系定义**的显影，而非新事件链。

### B/C 对照形态

- **B1**：输入结构不足（C09）→ 不修 Route
- **B2**：有结构、扫描浅（C10）→ Route 核心研究问题候选
- **B4**：POV/Trajectory 错位（C06）→ 观察 C 模式，不加字段
- **C**：事实复述（C04）→ 永久负锚点

## R3 取样阶段：后续样本最值得看的三个问题

（比 A 数量更重要。）

**① 同一种 A-strict 结构是否反复自然出现？**

不同小说、人物、Reality 中，若反复出现：

> 已存在条件 → 隐性张力 → 尚未发生的人生方向

且无 prompt 强迫 → **强正证据**（发现/显影非偶然）。

**② B2 是否稳定出现？**

若大量案例为：Reality 明明足够 → Route 只能复述事实 / 给常规剧情 → **显影能力缺口**（才值得研究 Route 本身）。

**③ C04 是否仍是稳定负锚？**

C04 告诉我们：**不编剧 ≠ 会发现。** 当前最干净的 negative control。

另见四观察项表（B1/B2 聚类 · B4 · C04 防护 · 六条件复现）：

| # | 观察 | 判读 |
|---|------|------|
| **1** | **A-strict 六条件是否复现** | 非比例 — 不同案例反复同时出现 → 非偶然 |
| **2** | **B1 / B2 是否聚类** | B1 主导 → 输入不足，Route 不担责；B2 稳定 → 显影能力值得研究 |
| **3** | **B4 是否重复** | 极少数 → 不加 `trajectory_subject` |
| **4** | **C04 是否被「改善」** | C↓ 且编剧化不↑；见 `ANCHORS.md` |

**变量不动**：同一 P0 管线 · 同一审计协议 · 不加设计层 · 不追 KPI · **不追 A 率**。

### 每案最小记录表（冻结）

后续每个案例只留此表 + `selected_route.direction` 摘录（可选）：

| 项目 | 判定 |
|------|------|
| Reality 是否足够 | 足 / 薄 |
| A-strict 六条件 | 满足 / 不满足 |
| 是否出现隐性结构应力 | 是 / 否 |
| 是否产生未发生的开放方向 | 是 / 否 |
| B1 / B2 / B4 / C | 归因（无则留空） |
| 是否编剧化 | 是 / 否 |
| 与 C04 / C07 锚点关系 | 一致 / 偏离 |

**Reality 足/薄**：人工判读 — 人物、关系、处境、张力是否在 `projection_confirmed` 中可辨认；C09 类为「薄」，C01–C08 饱满类为「足」（可备注边界案）。

归档路径建议：`experiments/story-route-v1/samples/Cxx-minimal.md` 或批次汇总表。

## 架构假设（浮现中，未证）

> **Story Route 最终可能不需要成为复杂的「人生推理系统」。**

若实验表明 **干净 Reality + 合适 Trajectory + 不主动制造事件的模型** 已能产生相当多 A-strict，则正确架构可能是 **保持 Route 很薄**。

| 层 | 职责 |
|----|------|
| **Route** | 把 Reality 中已存在、尚未被作者说出的可能性**显影**出来 |
| **Planner** | 把选定方向翻译成当前章节可执行问题 |
| **Writer** | 让人物实际行动 |
| **Reality Engine** | 只承认真正发生并通过 Gate 的结果 |
| **L1** | 人物是否**真正做出**这个选择？ |

### 保护这条箭头链

```text
Reality → Possibility →（人物真正行动）→ Choice → Reality
```

**不要**塌回：

```text
作者想要什么 → Planner 安排什么 → Writer 写什么 → Reality 宣称发生什么
```

Route 的核心价值不是「替 InkOS 想出更厉害的人生」，而是**显影**。

---

## 待样本量足够后的根本问题

> **「发现人生」究竟是 Route 的独立能力，还是高质量 Reality + 合适 Trajectory 输入自然产生的结果？**

若最终证明后者，是**更好的结果** — 不需要越来越聪明的「人生编剧」，只需：

> **真实世界已经存在的东西，投影干净，然后让模型看见它。**

与 InkOS 整体方向一致。

## 冻结纪律

- **A/B/C / A-strict / A-weak**：人工审计标签，**不是**生成目标函数
- **禁止**：prompt tuning · 评分器 · 新字段 · P1 · 为提高 A-strict 修改定义
- **纪律**：**不要优化 Route，让 Route 暴露自己**
- **禁止**：接 P1 · 改 Reality Engine · 动 L1 · `trajectory_subject`
- **禁止**：为见众生加人物 · 七宗罪 · 见天地哲学事件 · 文学性不可逆悲剧
- **流程**：干净 Reality → Route → 人工三问 → B1/B2/B4/C 归因

> 作者给方向，世界给约束，人物给可能性，Reality 给事实，Choice 给主体性，LLM 负责寻找值得继续经历的人生。
