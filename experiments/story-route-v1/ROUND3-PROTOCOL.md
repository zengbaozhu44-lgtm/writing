## 官方基线（R3 第 0 步后冻结）

| 标签 | 比例 |
|------|------|
| A-strict | **4/10** |
| A-weak | 2/10 |
| B | 3/10 |
| C | 1/10 |

**非 KPI**：不以提高 4/10 为目标；prompt 变强导致 A 虚高 = 实验失败。

**取样纪律**：变量不动 · 七行表 `SAMPLES-MINIMAL.md` · 只答两研究问题（显影结构跨案重复 · B2 聚类）

> **宁可证明 Route 目前不会发现，也不要通过修改实验让它看起来会发现。**

**核心研究问题**（比 4/10 更重要）：Route 是在「发现」人生，还是在高质量 Reality 上「显影」尚未显性的结构？靠样本区分，不靠争论。

**实验原则**：Route **不负责创造缺失的信息** — 找结构应力 → 展开开放方向 → 为 Choice 留空间。Reality 薄 → Route 平庸 **≠** Route 失败（见 `P0-STATUS.md`）。

验证对象见 `P0-STATUS.md` 一句话。

**判 A 纪律**：开放方向不因深刻/哲学/文学好听而给 A — 须能指认从 Reality 哪几个具体条件长出，否则降 B。

**实验环**：Reality 固定 → Route 固定 → 样本增加 → 人工判读 → 等模式出现。**不用再加任何东西。**

**第三轮看点**：显影结构跨案重复 · B2 偶发→稳定（非 A 个数）。

## A/B/C 定义（冻结为人工标签）

| 类型 | 含义 |
|------|------|
| **A：发现人生** | 从已有条件自然打开人生方向 |
| **B：普通剧情** | 合法、有可能，但未成为「发现人生」 |
| **C：事实复述** | 重新排列已有信息，开放空间极小 |

**禁止**将 A/B/C 写入 prompt、selector 或任何自动打分回路。

## 每一个 A 的三问反事实审计

理想 A 应接近：

> **过去中已经存在 → 现在刚好暴露 → 未来存在多个开放方向。**

对每条标为 A 的 `selected_route.direction` 逐问：

### ① 结构依赖

**如果删掉这条 Route，Reality 中是否仍然存在它发现的结构？**

| 回答 | 含义 |
|------|------|
| **是** | 结构已在 confirmed / bible / 人物状态中 — Route 是**暴露**而非**发明** |
| **否** | 倾向编造或过度投射 |

### ② 时态折叠

**如果把 Route 改写成过去时，它是不是基本就变成 Reality 的复述？**

| 回答 | 含义 |
|------|------|
| **是** | 倾向 **C**（或弱 A） |
| **否** | Route 在做**可能性展开**，非复述 |

### ③ 分支开放

**如果保留 Reality 不变，是否至少存在两个以上合理的未来展开？**

| 回答 | 含义 |
|------|------|
| **是** | 仍是 Route（可能性层），非 Plot |
| **否** | 接近单线剧情链 → 倾向 B 或弱 A |

### 审计结论字段（仅人工记录）

```text
A-strict   — 三问均通过
A-weak     — ①通过，②或③边缘
A→B 降级   — 审计后从 A 降为 B
A→C 降级   — 审计后从 A 降为 C
```

## B/C 实验矩阵（不可混谈）

四类对应**完全不同的系统问题**。永久锚点见 `ANCHORS.md`。

| 根因 | 锚案例 | 真正测试的问题 | 若反复出现 |
|------|--------|----------------|------------|
| **B1** | C09 | Reality 是否没有提供足够结构？ | **不修 Route** — 否则逼 Route「制造结构」（危险） |
| **B2** | C10 | Reality 有结构，Route 是否没发现？ | 才怀疑 `Reality → Possibility` 扫描能力 — Route 核心研究问题 |
| **B4** | C06 | Trajectory / POV 分离是否造成语义损失？ | 样本够再议 `trajectory_subject`；现在远未到 |
| **C** | C04 | Route 是否只是重述 Reality？ | 负锚点：开放可能 ↑ 且编剧化 ↓，否则是 Contract 风险置换 |

### B1 vs B2（最易混淆）

- **B1 反复** → 输入 Reality 结构不足 → **不能修 Route**
- **B2 反复** → 结构在、未发现 → **才值得动 Route 层观察实验**

### B3（次要轴）

| **B3** | Trajectory 过窄 | 作者走向只剩一个动作 | 侧车/案例多样性；C06 为次因 |

一条 B 可标**主因 + 次因**。

## 暂不升级 Contract 的观察项

### C06 — 语义对齐（非 G 类）

```text
Trajectory：林晓保住岗位
POV：       张北
Direction： 张北的岗位 / 系统距离 / 疑虑
```

未违反 Reality / L1。问题是 Route 能否在不加字段的情况下表达：

> **林晓是人生方向的焦点，张北是观察入口。**

继续观察，不加 `trajectory_subject`。

### C04 — 永久负锚点

见 `ANCHORS.md`。任何改动须问：事实复述 → 开放可能，且未增加编剧化。

### C07 — 正边界锚点

母亲陷阱：Trajectory 作观察方向，**不**实体化为事件。A-weak 但防过拟合。见 `ANCHORS.md`。
