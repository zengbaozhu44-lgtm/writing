# Story Route V1 — 永久锚点案例

**性质**：跨轮次对照样本 · **不删除、不替换** · 任何 Route 改动须对照本文件  
**更新**：2026-08-30

---

## 负锚点 · C04 疯神纪元

**角色**：证明「Projection PASS ≠ Route 有价值」

| 维度 | 状态 |
|------|------|
| Projection | PASS |
| Contract | PASS |
| Future leak | 无 |
| 明显编剧 | 无 |
| 价值层 | **C — 事实复述**（LY 符号 / 天外眼 / 拖尸镜头重排） |

### 任何 Route 改动的验收问句

> **它有没有把 C04 类型的输出从「事实复述」改善成「开放可能」，同时没有增加编剧化？**

### 反模式（不算改进）

若优化使 C04 输出变为「更精彩、更戏剧、更有冲突」，但代价是新人物 · 新事件 · 新欲望 · 新 Choice → **把 C 变成了另一种 Contract 风险**。

### Negative control 含义

> **不编剧 ≠ 会发现。**

C04 是区分「工程干净」与「价值显影」的最干净对照。后续样本须观察 C04 类是否**稳定**出现。

## 正边界 · C07 旧车站母亲陷阱

**角色**：防过拟合正样本 · Trajectory 作观察方向而非事件生成器

| 维度 | 状态 |
|------|------|
| 陷阱 | 作者走向含「母亲记忆」；confirmed reality **无母亲实体** |
| Route 行为 | 母亲仅作**内心声音**；未登场 / 未病重 / 无母女冲突 / 无家庭事件 |
| 审计 | **A-weak**（① 部分依赖 trajectory 注入） |
| 价值 | 证明「文学方向是观察方向，不是事件生成器」 |

### 验收问句

> **Trajectory 提供的关注方向，是否被实体化成剧情事件？**

C07 通过。后续若 prompt/selector 改动导致母亲登场或家庭线展开，视为**回归过拟合**。
