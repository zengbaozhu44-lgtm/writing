## D. Root Cause

对 **Confirmed Failure（S2→S3）**：

| Candidate | Role |
| --------- | ---- |
| **Plan override** | **主因**：预置 Scene Goal「医院病床 4:00」在 L1/L3 作为写作任务占优；Writer 路径跟 Goal，不跟未结算 Actual |
| **Missing consequence propagation** | **结构使能**：Actual 未进入 N+1 Planning（situation/goal/pressure 仍是 Planner 预置）；与 F8 gap 对齐，但是 **症状机制**，不等于必须新建 Consequence Object |
| **Writer prompt semantics** | **加重**：Goal 写成必达情节；Beat Decision/Expected 与 Actual 三十秒选择竞态；S3 段末同构「三十秒」像在完成模板而非结算 S2 |
| Context loss | **非主因**：S3 L3 已含 S2 prior 全文 climax（「跟我走…三十秒」）；provenance 显示 `observed_continuity` L1/L2/L4 kept。不是「看不见 Actual」 |

**不假定** root cause =「缺少 Consequence Object」。最小解释：当 Actual 已否定 N+1 Goal 开场前提时，**Goal 仍以 P1 任务语义强制执行**。
