# 写作圣经 · {{BOOK_TITLE}}

> 本书**唯一**写作规则源。世界观见 `01_world_bible.md`，人物见 `03_characters/`。

## A. 叙事原则（驱动剧情）

1. **现实目标优先** — 每章 POV 必须有可验证的当下目标
2. **利益驱动** — 选择 = 短期收益 vs 长期代价
3. **信息收费** — 情报不免费，获取必有成本
4. **人物主动** — 禁止被动等待异常降临
5. **世界不围主角转** — 后台势力并行推进（见 `state_board.md`）
6. **对话是博弈** — 每句有第二层意图
7. **每章不可逆变化** — 章末至少一项：物理 / 信息 / 关系

## B. 文风原则（驱动句子）

1. **身体先行** — 场景以生理反应开头，禁止以环境/信息/分析开头
2. **感官优先** — 信息寄生在物件与五感上
3. **信息寄生** — 禁止独立背景段超过 30 字
4. **异常反噬** — 能力使用即时付代价，异常不能当剧情发动机
5. **限知第三人称** — 不进入内心；内心独白每章 ≤ 2 句，且以问号结尾
6. **硬切节奏** — 禁止「然后 / 接着 / 突然 / 之后」

## C. 平台参数

| 参数 | 值 |
|------|-----|
| 单章字数 | 3000 |
| 对话占比 | 30%–60% |
| 结尾 | 动作或发现型钩子 |

## D. 禁止清单

- [ ] 解释设定（世界观须通过戏剧动作呈现）
- [ ] 全员上帝视角（POV 只能依据 `info_matrix` 行动）
- [ ] 异常推动剧情（须由目标受阻触发）
- [ ] 连续 50 字无身体反应
- [ ] 「他想起 / 他意识到 / 他觉得 / 他知道」

## E. 因果链（强制）

```
现实目标 → 受阻 → 利益计算 → 博弈/交换 → 不可逆变化 → 局势改变 → 下一章目标
```
