# 05 — Boundary Matrix v0.2

**Companion to:** Semantic Contract v0.2

| Boundary | Left | Right | Rule | Auto-promotion |
|----------|------|-------|------|----------------|
| Fact vs Option | Fact / Fact Access | Option Access | Knowing a fact ≠ seeing an action path as available to self | **FORBIDDEN** |
| Exists vs Access | World Possibility / Option Exists | Option Accessible | Objective possibility ≠ subjective availability | **FORBIDDEN** |
| Access vs Agency | Option Access | Agency | Seeing a path ≠ acting from narrated internal state | **FORBIDDEN** (Access alone) |
| Agency vs Choice | Agency | Choice | Agency is one conjunct; need Access ∧ Agency ∧ SubjectPresent for L1 VALID; VALID ≠ production Choice | Access/Agency alone **FORBIDDEN** → Choice |
| Presence vs Grammar | Subject Presence | Grammatical subject | Grammar ≠ Presence (both directions) | **FORBIDDEN** |
| Coercion vs Absence | External coercion | Subject Absence | Coercion ≠ Absence; P07/U08/I06 | **FORBIDDEN** auto |
| Historical vs Current | Past evidence | Current formation | Historical ≠ current Choice evidence | **FORBIDDEN** auto |
| Relevance vs Choice | Relevance / interest | Desire / Access / Agency / Choice | Relevance ↛ all four | **FORBIDDEN** |
| Action vs Choice | Action happened | Character chose | R8 | **FORBIDDEN** |
| Actual vs Choice | Actual event | Choice Authority | Actual ↛ Choice | **FORBIDDEN** |
| Judgment vs Production | L1 VALID | Production Choice | R13 | **FORBIDDEN** |
| Narration vs Authority | Writer decision language | Choice Authority | Narration ≠ Authority | Writer alone **FORBIDDEN** |
| Capability vs Access | Can physically / know how | Option Access in situation | Capability ↛ Option Access | **FORBIDDEN** |
| Desire vs Agency | Desire / characterPush | Agency | Desire ↛ Agency | **FORBIDDEN** auto |
| Pressure vs Agency | Pressure | Agency | Pressure ↛ Agency | **FORBIDDEN** |
| Lexical force | 必须/只能/不得不/被迫 | Absence / Agency | Non-automatic | **FORBIDDEN** auto |
| Irrationality vs Invalid | Bad option | L1 INVALID | R7; L1 ≠ rationality judge | **FORBIDDEN** |

### Distinct epistemic ladder (do not collapse)

```text
knows X
  ≠ understands X
  ≠ cares about X (relevance)
  ≠ considers X
  ≠ can do X (capability)
  ≠ has Option Access to doing X
  ≠ has Agency for doing X
  ≠ Chose X
```
