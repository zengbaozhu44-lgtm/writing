## A. OPEN-4 Question

> **For the prospective Phase 4 Character Causality path, what is the smallest semantic proposition that must be evaluated before Writer realization can legitimately produce a character-affecting Action, without allowing Plan, Director, Writer, GGC, Desire, or SR itself to become Character Choice authority?**

Operational form:

> Before Writer may realize `Character X performs Action Y` as **character-causal** (rather than Plan- / Director- / Writer- / SR-as-prompt-directed realization), what STORY TRUTH proposition about X and Y must already hold?

## C. Candidate Semantic Propositions

Maximum 3. Research only — no objects / schemas.

### P1 — Character-attributable Action Intent whose content is Y

| | |
|--|--|
| **Proposition** | Character X holds a character-attributable **Action Intent** whose content is Action Y. |
| **Minimum inputs (semantic)** | Character-side basis sufficient to bind Y as *what X is committed to do*; must not be identical to Plan / Director / Writer / Desire-alone / GGC-alone / SR-state-alone. Exact evidence recipe = **not designed here**. |
| **Output** | True / false / unknown that such Intent-to-Y holds (judgment only). |
| **Story Truth vs Control** | **STORY TRUTH** proposition (character-side causal commitment), not STORY CONTROL. |
| **Writer can establish?** | **NO** (may narrate; cannot mint authority). |
| **Plan can establish?** | **NO** (Plan Choice ≠ Character Choice; R10). |
| **SR alone can establish?** | **NO** (SR ≠ Intent ≠ Choice; W4). |
| **Relation to L1** | L1 is **not** this proposition. L1 has no pre-Writer input. Post-prose, L1 may audit formation *evidence* (Question A); `L1 VALID ↛` Intent/Choice mint (R13). |
| **Relation to GGC** | GGC = **optional input / contextual evidence** only; GGC ↛ Intent ↛ Choice ↛ Action. |
| **Relation to Candidate Option** | **NOT PROVEN REQUIRED.** Intent-to-Y does not logically entail an enumerated option set. |

### P2 — Production Choice that settles Y

| | |
|--|--|
| **Proposition** | A production Character Choice exists that settles Action Y for Character X. |
| **Minimum inputs** | Whatever OPEN-4 would require to mint Choice (unsealed); often assumed to include Access ∧ Agency ∧ SubjectPresent *in some layer* — not proven as production recipe. |
| **Output** | Choice record / authority that Y is the chosen content. |
| **Story Truth vs Control** | Intended as STORY TRUTH; currently **no sealed mint**. |
| **Writer / Plan / SR alone?** | **NO** / **NO** / **NO**. |
| **Relation to L1** | L1 VALID **insufficient** (R13); L1 ≠ production Choice. |
| **Relation to GGC** | Optional evidence only; not Choice. |
| **Relation to Candidate Option** | Often *assumed* required (“selected among options”); **NOT PROVEN REQUIRED** by this Gate; #25b blocks CO→L1. |

**Why not smallest:** Contract candidate architecture places **Action Intent** upstream of Writer (`[OPEN-4 Action Intent] → Writer → Prose → Actual`). Choice-as-mint is at least as strong as Intent-to-Y and may be stricter. Equivalence `Choice ≡ Action Intent` = **NOT PROVEN**.

### P3 — Mere opportunity for self-directed action (no binding to Y)

| | |
|--|--|
| **Proposition** | Character X has a valid opportunity for self-directed action (at *t*). |
| **Minimum inputs** | Some character-side openness / capacity (unspecified). |
| **Output** | Opportunity holds / does not. |
| **Story Truth vs Control** | Could be Truth-shaped; does **not** bind Y. |
| **Writer / Plan / SR alone?** | Writer **NO**; Plan **NO**; SR alone **NO**. |
| **Relation to L1** | Overlaps Subject Presence / Agency *themes* only; not identical. |
| **Relation to GGC / CO** | Neither establishes opportunity-as-OPEN-4. |

**Rejected as OPEN-4 minimum for realizing Action Y:** does not prevent Writer/Plan from choosing *which* Y. Too weak for “Character X performs Action **Y**.”
