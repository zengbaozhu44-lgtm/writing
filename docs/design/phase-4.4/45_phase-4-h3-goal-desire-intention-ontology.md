## 2. Terminology Matrix

| Term | Working definition | Is commitment? | Is selection among options? | Is world event? | Runtime today |
|------|-------------------|----------------|----------------------------|-----------------|---------------|
| **Desire** | Attractive / aversive pull toward or away from a state; may be passive, conflicting, unacted | No | No | No | Director desire profile = authored/`missing`; Reasoner fuel ≠ Authority; SR forbids Desire-as-fact bag from Plan |
| **Goal** | Currently active **orientation** toward an end-state the character is treating as to-be-advanced | Orientation yes; means not required | No | No | **No production Character Goal object** |
| **Intention** | Commitment to a **means** or near-term pursuit under a Goal (or attempt without clear Goal) | Yes (means) | No | No | **Absent** as object |
| **Candidate Action** | A possible act consistent with Desire/Goal/Intention/situation — listed, not selected | No | No | No | Candidate Option **NOT AUTHORIZED**; analytic only here |
| **Choice** | Formation/selection under Access ∧ Agency (and related L1 evidence) | Implies decisioning | **Yes** (formation/selection) | No (until acted) | L1 test-only; object **NOT PROVEN** (#35) |
| **Action / Occurrence** | What happened in prose / Actual | — | — | **Yes** | Actual / StoryEvent |
| **Plan (Authorial / Director)** | Story Control instruction for generation | Authorial | N/A | No | `chapter_plans` / 09 / intent — ≠ Character Goal |
| **Belief** | Held proposition | No | No | No | SR (authored / not auto from Actual) |
| **Stance** | Attitude toward a proposition | No | No | No | SR |
| **Concern / Interest** | Attention / caring without actionable orientation | No | No | No | Not a formal layer; must not = Goal |
| **Hypothesis (“would probably”)** | System/narrator guess | No | No | No | **Never** Character Goal Authority |

## 4. Boundary answers (required)

### 4.1 Desire vs Goal

| | Desire | Goal |
|--|--------|------|
| Nature | Pull / want | Active orientation to advance an end |
| May sit idle | Yes | If “Goal” but never pursued, may be mislabeled Desire |
| Enough alone for Plan fuel as character want? | **NO** | Still **≠ Plan**; even Goal ≠ auto Plan |

**Draft rule (for adjudication, not code):**  
Desire becomes Goal-eligible only with later Formation Gate (H3.3) — **not** assumed here.  
Explicit commitment language may matter; **not decided in H3.1.**

### 4.2 Goal vs Intention

| | Goal | Intention |
|--|------|-----------|
| End vs means | End-state orientation | Means / near-term commitment |
| Without means | Allowed | Degenerate / absent |
| Equals Choice? | **NO** | **NO** |

### 4.3 Intention vs Candidate Action

| | Intention | Candidate Action |
|--|-----------|------------------|
| Status | Character-side commitment (claimed) | Menu of possible acts |
| Count | Often singular / small set | Often many |
| Selected? | Oriented, not yet Choice | **Not** selected |

### 4.4 Candidate Action vs Choice

```text
Candidate Action = possibility in space
Choice           = formation/selection under Access∧Agency (L1 family)
Candidate ↛ Choice automatically
```

### 4.5 Choice vs Action

```text
Choice may fail to become Action
Action may occur without Choice object (#35: not every Action requires Choice)
Action → Actual (Occurrence)
```

### 4.6 Goal vs Plan

```text
Goal  = Story Truth orientation (character)
Plan  = Story Control task (authorial/director)
Goal → Plan direct identity = FORBIDDEN
Future research: Goal → Continuation Candidate → (Director evaluation) → Plan
```

### 4.7 Goal → Choice direct?

```text
NOT ALLOWED
```
