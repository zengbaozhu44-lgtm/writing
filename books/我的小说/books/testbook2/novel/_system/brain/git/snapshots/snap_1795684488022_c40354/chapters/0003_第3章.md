# 第3章

铁栅栏上的锈蹭了他一手。他退后半步，掌心那道红印还没散，指缝里嵌着碎锈，像干了的血。

天没亮透。

巷子窄，两边墙贴得近，头顶只留一道灰白。他站了一会儿，才觉出冷是从脚底上来的——鞋底薄，石板把夜里的凉气全存着，一点没散。

怀里的纸又软了。

他低头。纸角塌下去一块，像浸过水又被风半干。上面那行字，昨天还认得出，现在缺了一横，缺的那笔边缘毛着，不是撕的，是化开的——像纸自己在把字咽回去。

他把纸往怀里按了按。没用。他知道按不住，可还是按了。

巷口有辆板车过去，轮子碾在石缝上，咯噔一下。他没抬头。

昨晚从这扇门里出来的时候，纸比现在硬。他记得自己数过上面的字，十七个。今早再看，认得出的只剩十四个。剩下三个，笔画散在纸纹里，像谁用湿手指抹过。

他数到第七个的时候停了。手指悬在纸面上，没敢碰。

——碰了会怎样，他不知道。也不敢试。

天又亮了一线。栅栏后面那扇门还是关着，门缝里没有光。他昨天敲过，指节现在还留着一点钝痛，是门板太厚，震回来的。里面没人应。也没有脚步声。

他站着，等一个"里面会不会有人"的念头，等了很久，那个念头没来。来的只有冷。

他扶着栅栏，指节发白。锈腥气钻进鼻子。他忽然想起什么，低头看怀里——纸又塌了一点。就这一会儿。

他松开手，退开。

石板上一小摊水，是夜里凝的，还没干。他绕着走，鞋跟踩到边缘，水花溅起来，打在裤脚上，凉的。

巷子另一头有人开门。木轴转得涩，吱呀一声，拖得很长。一个女人的声音，隔着墙传过来，听不清说什么，尾音往上挑，像在问。另一个人答，闷闷的，两个字。

他往那边走了两步，又停。

不是那扇门。他记得那扇门的位置——朝南，门楣上有一块木牌，字磨没了。这扇不是。

他退回来，站在原处。

怀里的纸贴着胸口，凉。他能感觉到它一点点变软，像有东西在纸的另一面，慢慢把字吸走。吸走的不是墨，是别的什么——他也说不清，就是每看一次，那行字就更不像字一点。

他把纸抽出来，对着天光。

灰白的光透过纸，纸变得半透，能看见背后巷墙的砖缝。字在光里浮着，笔画断断续续。他盯着最清楚的那个字看——那是个"回"字，还完整。旁边一个，只剩半边。

他数到十，那个"回"字，外框缺了一角。

他把纸收回去。手在抖，他把手插进袖子里，压住。

巷子尽头的天，一点一点由灰转白。板车的声音远了。刚才那声开门，也没了下文，木轴大概是又合上了。

他站在门和巷口之间，没往前走，也没再敲。

脚底的凉已经上到膝盖。他动了动脚趾，鞋里进了水，趾缝间黏着，每动一下都凉。

他忽然想，这纸要是全化光了，他拿什么回去。

这个念头刚冒出来，他就掐断了。掐断的方式是咬住后槽牙，咬得腮帮子发酸。

不能想这个。

天光再亮一些的时候，他终于抬起脚，朝巷口走。走到一半，又停下。回头看那扇门。

门还是关的。栅栏上的锈，在光里发红。

他看了很久。

怀里的纸，又软了一层。他没低头，只是把胳膊收紧了些，把那点软，往怀里按得更死。

然后他转身，走进巷口的亮里。

巷口的亮是黄的，从高处漏下来，砸在他后颈上。

他站定。脚底的石板比巷子里烫。怀里的纸贴着胸口，软得像一块浸过水的棉，每走一步就往肋骨上贴得更紧。他抬起手——掌心的红印没消，指缝里的碎锈干了，卡在指纹沟里，像谁用针尖刻的。

前面是条横街。左边一个摊子，蒸汽从铁皮桶里冒出来，碱味。右边是堵墙，墙上贴了纸，风吹掉一角，露出底下的旧纸，一层叠一层。

他把手放下，插进口袋。锈蹭在布上，沙沙的。

“喂。”

声音从右边来。一个男人，靠着墙根蹲着，膝盖上搭了件脏外套。头发乱得像鸟窝，脸上有块青。

主角没停步，脚步慢了半拍。

“你怀里那个，”男人抬起下巴，“鼓鼓的，什么东西。”

他没答。继续走。

“我不是要你的。”男人站起来，膝盖响了一声，“我就问问。你要是去前面那家，我劝你别去。”

主角停下来。不是因为话，是因为那只手——从外套底下抽出来，手指缺了一截，断口是旧的，圆滑的疤。

“前面那家，今天不开。”男人说，“明天也不开。”

主角低头看了一眼怀里。纸的边角从领口露出来一点，白里透灰，软塌塌的。

“你怎么知道我要去哪家。”声音比自己预想的哑。

男人笑了一下，嘴角的伤跟着扯动。“这条巷子就一家。你从那边过来的，手上还有锈。铁门那家，对吧。”

主角没说是，也没说不是。指缝里的锈突然刺痒。

男人往旁边让了半步。“你要去也行。但你要是带着那张纸，进去之前，最好先看看上面写了什么。”

“为什么。”

“因为那家的灯，”男人抬头看了一眼高处，“照不了太软的东西。”

主角顺着他的目光抬头。亮光从一扇窗户里出来，玻璃上蒙了灰，光变得浑浊，像隔着一层水。窗户底下挂了块牌子，字迹被雨冲得只剩轮廓。

他低头，把怀里的纸抽出一角。纸已经软得不成样子，边角起了毛，上面的字——他眯起眼——墨迹洇开了，像一团化开的灰。

“你手别碰。”男人说，“锈吃墨。”

他把纸塞回去，收紧了胳膊。掌心那道红印开始跳着疼。

男人已经蹲回墙根，把外套重新搭在膝盖上。“我要是你，就先找个地方把手洗了。”

主角站着没动。风从巷口灌进来，碱味和铁锈味混在一起，说不清哪个更重。

他低头看自己的手。

巷口的光从高处漏下来，斜斜切过他的掌心。那道红印还在，边缘泛着白，像是被什么烫过又迅速冷却。指缝里的碎锈嵌得很深，他用另一只手的指甲去抠，抠不动，反倒把锈末推进了更深的地方。石头似的。

他握着拳走了两步。

巷子比他刚才进来时更窄了。两侧的墙面上有陈年的水渍，像地图上干涸的河道，一道道往下淌，终点消失在离地一尺的地方。他踩到一块松动的石板，边缘翘起，底下是湿的，黑泥混着碎瓷片。他蹲下去看了一眼——瓷片上有蓝色的花纹，半朵花，剩下半朵被断面吞了。

他站起来的时候，膝盖响了一声。

墙根的男人没动，外套还搭在膝盖上。从侧面看，那人的下巴有一道旧疤，从耳根延伸到喉结，颜色比周围的皮肤浅了不止一个色号。疤口平整，像是很久以前被什么薄而利的东西划过。

主角走到巷子中段，忽然停住。

他面前那面墙上，砖缝里塞着东西。不是纸，是布，暗红色，一角露在外面，被雨和灰浆浸得发硬，像一块结痂的伤口贴在墙上。他伸手去碰，指尖触到的瞬间，布料碎了，碎末沾了他一手，混合着铁锈和某种更甜的气味。

他退了半步。

巷子尽头是一扇门。木头的，门框已经歪了，上沿离墙有一指宽的缝。他刚才经过时没注意，因为门板颜色和墙面几乎一样——灰扑扑的，吸饱了潮气，表面贴着一张褪色的纸，边角卷起，上面的字被水泡过，只剩几个偏旁。

他把耳朵贴上去。

里面没有声音。但他后颈的汗毛立起来了，从尾椎到头皮，像有人拿指甲顺着他脊背划了一道。他咽了口唾沫，喉结上下滚动，嘴里泛着铜锈的味道。

他握住门把手。

铁做的，掌心那道红印刚好卡在把手的弧度里。疼。他攥紧了，没有松手。

门没锁。

把手转了半圈，铁轴里发出一声细响，像有什么东西被从很深的地方拽出来。他把肩抵上去。门板比想的沉，推开一条缝，风从里面挤出来，带着旧纸和铜锈的味道，贴在他脸上，凉。

他停了一下。掌心那道红印还在跳，一跳一跳，跟心跳错开半拍。

里面很暗。巷口的光漏进来，只够照到门槛内侧一小块地——灰的，被踩得发亮，中间凹下去一道弧。他迈进去，脚底下的木板叫了一声。

那声叫得不对。不是木头。太短，太干净，像有人贴着耳朵里面轻轻应了一下。

他站住。身后的门自己合上。没有风，也没人碰。

他回头。门板上没有把手。只有一圈浅浅的印子，铁的颜色，跟他掌心那块红印一样大。

他抬手，把手心贴上去。

凉的。凉了一会儿，慢慢变温，像贴着另一个人的皮肤。

他把手收回来。指腹上一层薄灰，灰里夹着一点红——不是血，比血淡，像被水洗过很多遍的朱砂。他蹭了一下，蹭不掉。

前面有光。很弱，从柜台后面透出来，一盏灯，罩子歪着。柜台很高，深色的木头，边角磨圆了，台面上放着一只小铜铃，铃口朝下，旁边压着一张纸。

纸是空的。

他走过去。走到一半，脚底下又是一声响。这次他听清了——不是木板。是下面有人在说话，隔着一层地板，隔着一层土，声音闷，字听不出来。

他蹲下去。地板缝里透出一线光。他把眼睛凑上去。

光没了。

他慢慢站起来，膝盖有点麻。柜台后面的灯还亮着，罩子歪着，火苗不动，一丝都不晃。

铜铃自己响了一声。很短。

他站在原地，手心的温度还没退下去。他想转身，左脚却先往前迈了一步。

柜台后面坐着一个人。

那人抬起头。脸在灯的背面，看不清轮廓，只有下巴和颈子的一截亮。他张了张嘴——先出声的不是那个人。

是柜台。木头里传出一句很轻的、他自己的声音。那是一句他还没说出口的话。
