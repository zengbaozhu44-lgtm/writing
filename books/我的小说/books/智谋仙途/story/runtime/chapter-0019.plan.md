# 第 19 章 memo

## 本章目标
林砚用仅剩一天一夜主动设局，在反向标记中验证布粉者真实意图，密道博弈从双向试探升级为正面交锋前夜

## 当前任务
林砚利用袖口云母粉被反向标记的事实，在白天设计一个“不可能完成的验证”——通过故意改变行动路线和信标放置方式，迫使布粉者在今晚做出回应，从而确认布粉者的真实目的（追踪还是另有目的）以及是否与茶摊老板为同一人

## 读者此刻在等什么
1) 读者期待林砚在被反向标记后如何反击——上一章尾句“找到了一个值得认真对待的对手”是强悬念钩子，读者想知道林砚的反制手段和布粉者的身份
2) 本章选择制造更强缺口：林砚开始设局，但布粉者同样在设局——读者会看到林砚的每一步计算，同时看到布粉者的回应存在超出林砚预期的变量，把“谁更高明”的悬念推到下一章

## 该兑现的 / 暂不掀的
- 该兑现：布粉者的行动模式在今晚回应中暴露更多线索（是简单反追踪还是有长期布局）→ 原则上可确认“非同伙”，但身份不揭，留到第20-21章
- 该兑现：身份揭示钩子中茶摊老板与取物者是否是同一人的证据链 → 本章给出70%确定性的推断（基于疤痕维度匹配+铁片风格差异），不100%确认，留一丝“可能另有其人”的空间
- 暂不掀：布粉者的具体身份（姓名、阵营）→ 留到第20-21章通过另一证据链锁定
- 暂不掀：铁片系统全貌（几个人在运行、信息链长度）→ 只确认至少两人，不揭示全貌
- 暂不掀：监视者的身份和动机 → 本章只埋“某个监视者通过新渠道获知了林砚的行动信息”的线索，不揭示是谁

## 日常/过渡承担什么任务
不适用 - 本章无日常过渡，全天高压博弈：白天部署验证系统+夜晚伏击观察+检查布粉者回应

## 关键抉择过三连问
- 主角本章最关键的一次选择：林砚决定改变信标放置位置——从习惯的“暗格内”改为“暗格外侧的标记石下”，且不放置新铁片
  - 为什么这么做？他想测试布粉者是按照固定路线追踪信标，还是能预判他的变轨——如果布粉者找到标记石下的位置，说明布粉者对他的了解已经超过“观察物理痕迹”的层面，可能是通过其他方式（预判认知模式、内部信息泄露）
  - 符合当前利益吗？符合——他需要在最后一天一夜确认对手的真实层级，如果对手水平超出预期，他必须立刻调整后续策略；如果对手水平未超预期，他可以按原计划在窗口期截止前完成系统部署
  - 符合他的人设吗？符合——他从不做无准备的冒险，但这是他通过计算过的风险（用“放错位置的饵”换取“对手真实水平的信息”），不是无脑行动；同时这个行为暴露了他对布粉者的警惕正在升级——从“想赢”变成了“想知道自己能不能赢”，这是隐忍型角色的正常心理变化

- 对手/配角本章最关键的一次选择：（布粉者）在看到林砚改变信标位置后，选择“照常更换”还是“针对林砚的变轨进行反制”
  - 为什么这么做？取决于布粉者的真实目的——如果是单纯追踪系统维护者，会照常更换（让系统持续运行）；如果林砚也是被追踪对象，布粉者会用某种方式回应变轨（改变标记方式、留下威胁信号、或完全避开以制造信息真空）
  - 符合当前利益吗？两者的答案不同：如果布粉者是追踪者，不回应新位置更符合利益（不暴露自己的存在）；如果布粉者是第三方棋手，回应变轨反而可能落入林砚陷阱。布粉者最终选择一种介于两者之间的回应方式——既不完全忽略也不完全配合，压迫感升级
  - 符合他的人设吗？如果布粉者是茶摊老板，他性格多疑有组织背景，不会完全无视林砚的变轨也不会全响应——他选择在标记石下留下一道极浅的刮痕（类似宗门内部“已阅”的暗号），同时在暗格内留下一个不属于本宗的灵材碎片。这符合一个“既有纪律又有自主权”的潜伏者行为模式

## 章尾必须发生的改变
- 信息改变：林砚确认布粉者有组织背景（基于刮痕暗号和灵材碎片），推断铁片系统运行时间超过三个月（基于第二块铁片氧化层分析），且布粉者的人数≥2（基于刮痕风格与灵材类型不匹配）
- 关系改变：林砚与布粉者从“双向试探”升级为“彼此知道对方存在但双方都选择不掀桌”——双方默认这是一个有限博弈，在窗口期结束前互相测试上限，但不直接冲突
- 权力改变：林砚不再是被追踪的猎物，也不是纯粹设局的猎手——他变成了一个“知道自己被观察、主动暴露部分弱点来获取情报”的双面角色；布粉者同样如此

## 本章 hook 账

open:
- [new] 铁片暗格的字符背后存在篡改痕迹（某笔划被磨掉后又重刻过） || 理由：在林砚白天拆解第二块铁片时发现字符有二次加工痕迹，暗示信息链曾被人为修改过，布粉者可能不是铁片系统的原始设计者——这为后续“谁在设计铁片系统、谁在篡改信息”埋钩子；不在本章揭是因证据不足，需后续多块铁片横向比对

advance:
- identity-揭示取物者身份-通过左手腕疤痕与茶摊老板 → 林砚通过白天跟踪茶摊老板一次非日常行动（前往杂役区后山埋东西），确认其左腕疤痕的维度（弧长、宽度、凹陷位置）与夜间目击高度吻合，同时发现茶摊老板正在私下接触一个非本宗身份不明者 → 从 open → near_payoff（证据链完成70%）
- H08 密道信标系统 → 林砚通过实验确认布粉者能预判他的变轨，且布粉者更换信标的反应速度比他快（在林砚触发变轨后不到15息内完成调整，说明布粉者一直在不远处观察）→ progressed → advanced（从“系统运行证据”到“系统管理者的实时监控能力”）
- H10 确认铁皮来源、完整字符含义、与主线关联 → 林砚白天在三处不同位置收集了茶摊洒落铁屑，比对暗格铁片材质，确认铁片来源为宗门锻器堂特供矿石（含三成陨铁粉）→ progressed → advanced（物品来源锁定，但字符含义和关联仍悬置，需后续铁片）
- H11 揭示洞口内物品系统性质 → 布粉者今晚的回应（刮痕暗号+灵材碎片）揭示系统不仅是“信标交换”，还有标记跟踪功能——物品的来回移动一直在信息链上被记录和传递 → progressed → advanced

resolve:
- 饵线反噬-老者箴言验证 → 林砚在发现袖口云母粉后，不仅理解了“饵变线”的含义，还在本章主动用自己的被标记状态设计了新的饵——将错就错，利用布粉者已经掌握他的行动模式来反向锁定布粉者的“信息偏好” → 融入了行动，完全兑现
- H03 窗边监视者的信息差异 → 林砚在白天检查茶摊老板行动路线时，无意中发现一处被翻动的落叶堆下有不属于本宗的草药渣，暗示“还存在第三个知晓密道入口的人”，但不确认是监视者还是其他人 → 部分resolve（确认存在第三方，但身份未知）

defer:
- window-watcher 监控者身份 → 本章不动，理由：已有E03草药渣的线索暗示第三方存在但不适合在此章揭示，留到第20章通过铁片系统另一端的持有者来连接

**硬规则遵守**：
- H03（天道缺陷）状态=progressing，已沉默18章 → 本章通过草药渣线索partial advance，但未完全reveal（留悬念），符合“至少advance或resolve”的要求
- window-watcher（监视者）状态=progressing，已沉默16章 → 标记为defer并写明理由（第20章连接铁片系统另一端的人物揭示）
- H10（铁片来源）已沉默5章 → advanced（锁定宗门锻器堂矿石来源）
- H11（系统性质）已沉默5章 → advanced（揭示标记跟踪功能）
- resolve数量≥open数量：resolve 2条（饵线反噬+H03部分） vs open 1条（铁片字符篡改），open ≥ resolve的底线满足（reason: 本章是高压推进章，新钩子不宜超过2条）

## 不要做
- 不要在白天段落中写林砚与茶摊老板的直接对话或正面接触——林砚在以“跟踪+观察”方式验证身份，不是用对话验证
- 不要在本章揭露布粉者的真实名字或阵营归属——只写行动特征和痕迹证据，身份留到第20-21章通过一个间接但强力的证据链（如铁片字符篡改的关联方）来逼出
- 不要写林砚“全胜”——布粉者的回应不完全在林砚预期之内，体现出“双方在同一个水平线上博弈但各有盲区”
- 不要忽视核心心法“甜必藏刀”——本章林砚的每一个“胜利”（确认身份线索、推进铁片调查）必须在同一段或下一段立刻给出代价（发现信息被人先一步修改、时间窗口只剩最后一天、发现还有第三人在漏网）
- 不要违反“5-1.5-2”比例——本章智谋占主（60%）、羁绊占一点（林砚在无人处默念一次宋时的名字，半句不提具体内容，但暴露了他还有一个未被触及的软肋，大约占10%），命运占15%（铁片系统被人为修改暗示有一只看不见的手在设计一切），武力占5%（林砚在攀爬过程中一次精准的手脚协调，不战斗），其他10%（纯环境描写+林砚在雨后的心理落点，一人观雨）
