# EO-4.4-41 Experiment Protocol

## Goal

Prove whether the **current** Actual-enabled mainline can:

```text
PROSE → ACTUAL → PERSIST → READ → NEXT CONTEXT → NEXT PROSE
```

with observable story effect — without implementing new modules.

## Seed facts (hoped for in Ch1 prose; not forced into Ch2)

| ID | Kind | Expected Ch1 occurrence (if Writer follows plan) |
|----|------|--------------------------------------------------|
| F1 | Object handoff | 苏晚把配电间备用钥匙交给老何 |
| F2 | Information | 苏晚得知「周四下午三点」相关安排 |
| F3 | Relationship | 苏晚与老何从争执转为勉强合作/撕破脸后协作 |
| F4 | Open matter | 漏水未修；周四约定未兑现 |
| F5 | Action | 苏晚下楼对质 / 交出钥匙等实际行动 |

## Observation levels

- **A Persistence**: fact → actualEvents / sidecar
- **B Consumption**: next Scene/Chapter context contains it
- **C Story Effect**: next prose attitude/state/conflict actually shifts because of it

## Forbidden

No code/schema/golden changes. No Choice / Survival / Phase 5. No auto-fix.
