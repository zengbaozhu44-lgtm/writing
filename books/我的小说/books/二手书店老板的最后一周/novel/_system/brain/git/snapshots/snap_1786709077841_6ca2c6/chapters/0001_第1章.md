# 第1章

铁皮门轴那声响还没落尽，林守常已经看见那片叶子。门槛内侧，叶尖朝里。他脚步骤停，喉结滚了一下。晨风从巷口灌进来，吹得叶柄打了个转——纹丝不动，像从砖缝里长出来的。他蹲下去，没碰，先看叶背。没有虫眼，没有焦边，叶脉完整得过分。八月末，巷子里只有樟树和槐树。他拇指和食指捏住叶柄，提起来时手背青筋绷了一下，指腹擦过叶面，搓下一点湿凉。是露水。后半夜落进来的。

他直起身，推开书店下半截窗板，把那片叶夹进柜台边一摞书里——不是《植物名实图考》，是压在下面那本封皮发黄的《救荒本草》。指尖压着书脊，他停了停。煤炉在屋角，铁皮壶里的水还温着。他没动，

煤炉铁皮冷得像昨天刚死过。他伸手摸火柴，抽屉半开的缝里，灰影子拱了一下——"目录"探出半个头，胡须沾着旧书灰，眼睛眯成两条缝盯着他。

火柴划了三次才着。火苗舔上炉膛时，铁壶底的水响了一声，像有人在里头叹气。

"目录"跳上柜台，爪子按在那片叶子上，回头看他。煤烟呛出来，他咳嗽，喉咙里带出一句含混的骂。抽屉还半开着，里头空

抽屉空得像被掏走了肺。林守常盯着那片叶子，指腹搓过叶脉——干透的脆响在指缝里碎成粉。他把叶子翻过来，背面沾着半粒灰白的鸟粪，风干很久了。门没关严，晨风掀动书页，哗啦一声像在催他。

他攥紧叶子，指节发白。抽屉合上时磕了手背，疼得他嘶了一声。

“留着。”他对着空屋子说，声音哑得像砂纸蹭铁皮。叶子被他

掌心被叶柄硌出白印。他松开手，叶子落在柜面上，背面朝上——灰白的鸟粪边上，还粘着半截透明胶带，像是从什么旧信封上撕下来的。周岚昨晚来送过一袋书，捆绳松了，他记得她蹲在门口理书时，袖口蹭过的就是这扇门框。

他忽然蹲下，指腹去摸门槛内侧那道旧钉眼。去年钉过一块铁皮挡雨，后来拆了。钉子还在，铁皮没了。

外头

外头的天还没全亮。林守常顺着那道钉眼往下摸，指尖在门槛底侧碰见一片干枯的梧桐叶，叶脉完整，边缘卷起，像被人特意按进缝里的。

他捏着叶柄抽出来，指腹碾过叶面——背面有字，圆珠笔写的，笔画被潮气洇开，只认得出半个「周」字。周岚的字。她从不往书里夹叶子，她说叶子会碎，碎在书页里像骨头。

林守常把叶子翻过来，对着门口漏进来的光。字迹朝上，

字迹朝上，那半个「周」字被光从背面顶起来，竖钩的收笔拖得比周岚平时长——像是写的时候手在抖。林守常拇指按在笔画上，潮气已经渗进纸纤维，指尖凉得发木。

他转身拉开抽屉，铁皮盒里压着一叠旧书签，最底下那张是她去年留的，写着「等我」。两处笔迹并排搁在柜台上，横折的角度差了两度，周岚写口字从不封口，这张封了。

书是下午两点四十分搁上柜台的。林守常正在给《说文解字》补虫蛀的封底，糨糊刷到一半，听见塑料绳勒紧书脊的声响。他抬头，老周站在柜台外，指节按住书封，没松手。

“三年。”老周说。

林守常放下刷子，拇指蹭过书脊那道裂口，胶痕硬得像结了痂的伤。他没接话，从抽屉底层摸出那把牛角刀，刀尖沿着旧胶线走了一遍，手

刀尖顿在裂口尽头。老周的手没动，指节压着书封边缘，青筋鼓起来，像根绷了太久的弦。

“修了，就不是那本了。”老周说。

林守常的刀悬着，没落下去。柜台上的橘子滚到《辞海》边沿，停住。他听见自己牙关咬紧的响，像咬住一句不该出口的话。

糨糊刷进裂缝，把“雪”字两半摁回一处。他拇指压着书脊，等胶干。窗外的蝉叫得像锯条，他忽然说：“那橘子，是阿婆园里的？”

老周没答。橘子在柜台上转了小半圈，停稳。林守常把书合上，搁进牛皮纸袋，纸袋口折了三折，递过去。老周接了，没走，从兜里又摸出一个橘子，放在纸袋上。

橘子滚到柜沿时停住了，像被什么看不见的东西挡了一下。林守常没去扶，指尖嵌进果皮，油性汁水溅上虎口，酸味冲进鼻腔。他掰下一瓣，手背青筋绷着，往台面下递。

猫没来。

第二瓣塞进自己嘴里，嚼了两下，酸得牙根发麻。他咽下去，又掰一瓣，这回没递也没吃，搁在掌心，看着它发呆。报纸窸窣展开，橘子瓣裹进去，

老周的背影刚消失在巷口拐角，林守常的手已经够到那只橘子。皮在指腹底下裂开，汁水溅到《新华字典》烫金的字缝里。他没擦，掰下一瓣搁进食盆，瓷底磕出一声脆响。「目录」没动，耳朵竖着朝门口方向。

他嚼着第二瓣，酸得牙根发紧，把剩下的橘子用柜台底下垫过书的旧报纸裹了，塞进抽屉最里侧。

然后他抽出口袋里那片枯叶。叶柄断口

叶柄断口处的毛刺，被汗洇软了，贴在指腹上像一小片活物。他翻过叶面，背光看叶脉的走向——主脉在近叶尖处岔开一道细杈，不该有的。他正要用指甲沿那道杈划开，巷口传来三轮车链条绞紧的声响。收旧书的秃顶男人探头喊：“老周那套《陶庵梦忆》你收不？他下周三清房子，堆门口当废纸卖。”林守常手一抖

三轮车突突远了。林守常的拇指还压在叶脉上，断口对着光，像一张没闭上的嘴。他听见自己的心跳撞在肋骨上，闷的。橘子从《新华字典》上滚下来，磕在柜台边缘，青皮磕出一道白痕。

他伸手接住。橘子凉，凉得他指节发僵。他攥着它，转身走到煤炉边，把糨糊瓶盖上盖，塞进柜台底层的铁皮盒里。铁皮盒里已经躺着三片枯叶，各

老周那本《陶庵梦忆》还压在煤炉边，胶痕在热气里泛着白林守常把橘子搁在柜台上，手掌按着它滚了半圈，青皮上的白痕像道浅疤。他听见铁皮盒里枯叶的脆响，三片，都是梧桐。他猛地合上盒盖，金属磕在指关节上，疼得他抽了口气。

“下周日。”他对着煤炉说，声音被热气吞了一半，“搬完这屋，我送你到车站。”

老周没接话，手指在柜台上划了道线，指尖蹭过橘皮，留下一小片油亮。他转身时，风从门缝挤进来，吹得煤炉火苗歪了歪。

“车站不用送。”老周在门口停住，没回头，“我搭凌晨那班绿皮，五点半到站，票已经买了。”

林守常盯着他后颈那道旧疤，突然想起什么，伸手从柜台底下摸出个牛皮纸信封，抽出一张泛黄的存单，日期是三年前的。他把它按在柜台上，往前推了半寸。

存单压在柜台上，边角卷起，露出“叁仟元整”的铅印。林守常指尖按住日期，三年前的秋天，九月十四。老周搬走那天，隔壁修车铺的卷帘门拉下来之前，他往这边递过一壶茶。

“钱垫着，书先放着。”林守常把存单推回去，声音在喉咙里滚了一下，“你那本《陶庵梦忆》，我修好了，下周日你来取。”

老周没接存单，指尖在柜台上敲了两下，像敲钟。“书你留着。我要是回不来，就当寄存。”

门合上了。煤炉的火苗晃了晃，又直起来。林守常的手指在柜台边沿停了几息，才把橘子拢进掌心，指甲掐进青皮，汁水洇湿了指缝。他剥得很慢，白络一丝丝扯断，像拆一段旧线头。第一瓣放进那只豁口的搪瓷食盆，第二瓣自己嚼了，酸得牙根发紧。剩下的他用报纸裹紧，塞进抽屉最里侧，压在那张存单上面。

抽屉合上时，他摸到早上那片枯叶。叶脉干透，边角卷成脆壳，像一片烧焦的蝴蝶。他把它夹进《陶庵梦忆》，翻到“湖心亭看雪”那一页。书脊新换的麻线绷得笔直，枯叶卡在“天与云与山与水”那句上头，压出一道浅痕。

关门时，他习惯性地抬手，中指缺了半截的指节蹭过门框上那颗旧钉子。钉子生锈了，木纹里渗出一道赭色痕迹，像是那年挂“今日营业”木牌时，钉尖斜着吃进去，留下的一道岁痕。牌早不在了，钉子还在。

他摸了两遍，指腹碾过锈迹，停住。门框上方，钉眼周围有一圈新刮的划痕，木屑还新鲜，像是今天早上才留下的。他仰头看了三秒，又低头去看夹在书里的枯叶。叶片的形状和那颗钉子的位置，像是从同一个地方下来的。他攥紧门把手，没回头。
