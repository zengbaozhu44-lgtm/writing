# 第1章

林守常把叶柄举到煤炉前，火苗刚舔上报纸边沿，光从叶脉的孔洞漏过来，像一小片筛网。他指腹顺着叶片卷曲的弧度压了压，那里有一道浅褐色的折痕，不是自然弯折——是被人对折过，又展平了放下的。他盯着那道折痕看了两秒，把叶子重新夹回书里，这次没放柜台，塞进了外套内袋。

炉膛里煤块炸开第一声响，火苗蹿上来，把报纸烧成灰白的薄片。'目录'从抽屉缝里探出半截耳朵，胡须颤了颤，又缩了回去。林守常把茶壶坐上炉子，壶嘴喷出的白汽烫到手背，他缩手，碰到口袋里的书脊，硬邦邦的，硌着肋骨。他咽了口唾沫，喉咙里像卡着糨糊，黏的。

壶嘴的白汽还没散尽，门轴就响了。老周站在门槛外，腋下夹着那本《陶庵梦忆》，书脊朝外，脱胶的裂缝像一道张开的嘴。

“湖心亭那页，雪字裂了。”

林守常伸手去接，指尖碰到书脊时，老周没松手。两人隔着门槛僵了半秒，老周的目光越过他肩头，落在柜台角落那本《植物名实图考》上——书页间露出一角枯黄。

老周的手腕抖了一下，书脊在他掌心里压出一道白痕。“那叶子，我老伴去年夹的。”他说，声音像是从嗓子眼里挤出来的，“她走那天，巷口那棵梧桐正好落叶。”

林守常没动。他低头看着自己指尖还搭在书脊上，老周指节泛白，指甲掐进封皮里。柜台角落那本《植物名实图考》的书页间，枯叶露出一角，边缘卷着，像一只攥紧的手。

门轴响了一声，风从门槛缝灌进来，吹得那页书角翘起又落下。林守常的拇指还按在书脊上，指尖抠进胶痕里，像要把什么钉死。

“修。”他说，声音从牙缝里挤出来，“下周搬，我帮你搬。”

老周的手松了，封皮上留下四个白印。他往门口走，到门槛边停了一下，回头看着柜台角落露出半边的枯叶。

“那本书，”老周说，“里面夹的叶子，是梧桐。”

门帘哗啦响。风灌进来，把煤炉边的灰卷起半圈。

“周叔，”他开口，声音先落下去，才续上，“上回你说搬去南边，几号？”

老周指头在橘皮上顿了顿，像在掂量什么，又缩回去。他弯腰捡起那截断线头，缠在指节上绕了两圈，才抬头：“南边，下月三号。”

林守常的糨糊刷子停在半空，刷毛上挂着一滴，悬着没坠。他盯着那滴糨糊，喉结滚了一下，把刷子放回瓶口，指腹在瓶沿蹭了蹭。

林守常捏着那截线头，指尖来回捻了两遍，粗糙的棉线刮过指纹沟壑。他低头把线头绕在《陶庵梦忆》的书脊上，打了个死结，手背青筋鼓了一下。

“南边，”他开口，声音压得又低又平，“下月三号，是清明前夜。”

老周愣住了，扯线的动作僵在半空。林守常却笑了，牙根咬得紧：“我把书送到南边，你人呢？”

林守常把糨糊瓶往柜台上一磕，瓶底震出一圈白沫。“你走你的。”他指头戳了戳那本《陶庵梦忆》，“书留下，人我不留。”

老周的手指在塑料绳上搓了两下，绳头散成毛边。窗外扫过一阵风，煤炉里的火苗歪了歪，墙上的影子跟着晃了半尺。

“清明前夜，”老周忽然低头，拇指抠着书脊裂缝，“你爸当年走的那天，也是这个日子。”

糨糊瓶沿上的手指慢慢收拢，指节泛白。他想起那个清明，父亲把一摞书码在门槛上，说“守好它们”，然后就没再回来。煤炉里的火苗又歪了一下，这回没直起来。

“你也是来还书的？”林守常听见自己的声音，干得像纸页边缘，“还完就走？”

老周没抬头，拇指还在裂缝里抠着，半晌，说：“书可以修，人修不了。”

柜台角落那只搪瓷缸沿上，落着一层灰，灰里印着半个猫爪印。林守常盯着那爪印看了两秒，拇指蹭过去，灰没了，爪印也没了。他缩回手，指尖在裤缝上蹭了蹭，像蹭掉什么不该碰的东西。

橘子还搁在收银机旁。他拿起来，皮凉，贴着手心。剥的时候指甲掐进油皮里，一股涩味冲上来，他没停，撕下第一瓣，塞进嘴里。酸得牙根

酸得牙根发软，他咽下去，喉结滚了滚。橘络卡在齿缝里，他用舌尖去顶，顶出满嘴清苦。

柜台上那本《陶庵梦忆》还摊着，雪字裂成两半。他伸手去抚，指尖触到纸面时，窗外有人喊收旧书，声音闷得像隔着水。

来不及了。他猛地合上书，塑料绳没系，书页哗啦一声扫过掌心。还剩四天。

窗外那声“收旧书”沉下去，像石子落进井里，半天没个回响。林守常攥着书脊，指节发白，塑料绳在掌心勒出一道红痕。

他低头，看见自己另一只手还按在《陶庵梦忆》那页裂开的雪字上，指腹蹭过纸面，微微发颤。

“四天。”他说出声，声音撞在四壁又弹回来，干巴巴的，“够干很多事，也够什么都没了。”

他松开绳子，门轴吱呀一声，晨光像摊开的旧报纸铺进门槛。林守常低头，看见门槛内侧躺着一片梧桐叶，叶脉枯黄，边缘卷成半圆，像是被人特意放在那儿，又像是被风从门缝里塞进来。他弯腰拾起，指腹蹭过叶面，干涩的触感让他想起昨天《陶庵梦忆》里那页裂开的雪字。他夹进《植物名实图考》里，压在第47页与48页之间，那里正好有一幅梧桐的插图。

煤炉引燃时，火苗蹿起来又缩回去，青烟在晨光里扭成细线。他蹲着拨弄炉灰，听见身后抽屉“咔哒”一声轻响。回头，那本《植物名实图考》的“目录”页探出半个角，像什么东西从书页间探出头来。他盯着那角纸，时间忽然变得黏稠，像糨糊一样糊在喉头，咽不下去，也吐不出来。他伸手去按那页纸，指腹刚触到纸面，抽屉深处传来一声极轻的金属磕碰声。

他拉开抽屉，那串钥匙躺在最里角，六把铜钥匙，齿痕深浅不一。他数了三遍，都是六把。可第三遍数完时，指腹硌到一道陌生的齿痕——抽屉底板有道缝，缝里卡着半截断钥匙，锈得发黑，断口却是新的，铜色还没氧化透。他撬出来，对着炉火的光看，钥匙柄上刻着一个“周”字，笔画歪斜，像小孩用指甲划的。炉火噼啪一响，火舌舔上来，林守常猛地缩手，指腹已经烫出一道白痕。他低头看那字，锈迹顺着刻痕洇开，底下一行小字，被铜绿糊住了大半。他凑近炉光，认出来——“周，欠林，一命”。

门外的风忽然灌进来，吹得炉灰扑了他一脸。钥匙从指间滑落，当啷一声，滚进柜脚阴影里。他没去捡，蹲在原地，盯着那截断钥匙，喉结滚了一下。搬家公司昨天打来电话时，他报的是老周家的地址。可老周上周就搬走了，那间屋子现在空着，门锁换过，钥匙孔里塞着新漆的铜屑。他伸手去够柜脚阴影里的断钥匙，指尖刚碰到冰凉的铜面，门外忽然传来脚步声，停在门槛前，不轻不重，敲了两下门。
