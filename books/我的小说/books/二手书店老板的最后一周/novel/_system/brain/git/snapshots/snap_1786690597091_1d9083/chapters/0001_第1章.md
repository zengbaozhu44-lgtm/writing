# 第1章

门轴转开时，冷气先扑上他的脸。门槛内侧躺着一片梧桐叶，叶面朝下，叶柄断口发白。

林守常蹲下去，没立刻捡。他先看门槛——昨夜的露水在砖缝里凝成一条细线，叶子的位置正好压在线中间，像是被谁掐着时辰放下来的。他把它夹进柜台上一本《植物名实图考》里，书卖了八年，塑封都没拆。

他直起身时，手指在叶柄断口上碾了碾，指腹沾了一层潮气。不是风吹落的，是揪下来的，断口还软着。

“操。”

他低声骂了一句，喉咙里那截气没吐完，转身去煤炉边划火柴。火苗舔上纸煤时，他手腕抖了一下，炉膛里“噗”地窜起一股白烟。

抽屉里“目录”翻了个身，它的耳朵抖了抖，没有别的动静。

老周把书拍在柜台上，塑料绳勒进书脊，像道旧疤。

“《陶庵梦忆》。”他解绳子，指节发白，“湖心亭看雪那页，你夹了东西。”

林守常没接。他看见书页间探出一角枯黄——梧桐叶的尖。他今早刚夹进去的那片，叶柄断口还带着露水。

“我没夹过。”老周的声音低下去，像在跟自己说话，“但页角折了，折痕是新的。”

炉膛里煤块炸了一声。他猛地攥紧叶子，指节发白，后脊一层冷汗。老周上周三才说过，周日去省城看女儿，三天回不来。他蹲在原地没动，风从门缝灌进来，把他后背的汗吹成冰。

林守常的手指停在书脊脱胶处，指腹按进那道裂口，能摸到纸浆粗糙的毛边。老周的手还悬在半空，指节上沾着煤炉灰，在日光灯下泛一层青白。

"三年。"林守常听见自己的声音，喉头像被砂纸磨过一道，"你借了三年。"

“老周。”他喉头动了一下，“这书，你三年前借的时候，书脊就是裂的？”

老周在门口站定，背影逆光，没回头：“你记错了。三年前我借的是《夜航船》。”

《陶庵梦忆》横在柜台上，修好的书脊还带着炉温，微微拱起一道弧。他把枯叶贴着那页湖心亭雪景压进去，合上。书缝里露出半片叶缘，像书签。

他抓起那枚橘子，没剥，塞回兜里，转身去关门。门闩落下的声响，震得耳膜里那根弦嗡嗡颤了半天。

橘子滚到收银机旁停住了。林守常没看它，走过去，手搭上门沿——指尖先碰到一个东西。钉帽。半截生锈的铁钉，不知什么时候钉进门框里，露出约莫一厘米。他拇指按住钉帽，往里推。推不动。钉身锈死在木头里，像长出来的一样。门缝里塞着一张纸，叠了两折，边缘裁得齐整。他抽出来，展开：等你。字是铅笔写的，笔迹有点抖，像是写了不止一遍。

老周的背影刚没入巷口，林守常的手就伸向那个橘子。指腹压进橘皮，油星渗出来，他闻见了——酸甜，带着一点涩。手有点抖，他握紧，让指甲掐进皮肉里。

猫没出来。他掰下一瓣，搁在柜台边缘，自己那瓣咬下去，酸得牙根发紧，差点骂出声。他把剩下的橘子用柜台下翻出的旧报纸裹了三层，塞进抽屉最里角，压在一本《庄子》下面。

然后他拉开抽屉，指尖在纸页间摸索，触到那片枯叶——干、脆、薄如蝉翼，边缘卷曲，像一片从旧时光里剥落的灰指甲。他把它夹进刚修好的《陶庵梦忆》，“湖心亭看雪”那一页，轻轻合上，手指在书脊上停了一瞬，仿佛在确认什么。

他起身，走到门边，木门发出钝响。他抬起右手，缺了半截的中指抵住门框上那颗旧钉子——光秃秃的，钉帽磨得发亮。曾经挂在这里的木牌不在了，但钉子还在，像一根扎进骨头里拔不出的刺。他指腹摩挲着钉帽，忽然停住。

巷口传来猫叫，细弱，像婴儿的哭声。他回头，柜台边缘那瓣橘子已经不见了，只剩一小片湿痕，在灯下慢慢干涸。他转回头，手指还搭在钉子上，没有摘下来。
