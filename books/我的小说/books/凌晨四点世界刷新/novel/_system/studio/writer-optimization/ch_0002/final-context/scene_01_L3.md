## Priority 0 · Professional Writer Craft
**Director 决定故事写什么；Writer Runtime 决定故事如何写得好看。**
**先问**：职业作者会不会这样写？

### Show, Don't Tell
禁止：意识到 / 觉得 / 知道 / 害怕 / 紧张 / 震惊 / 恐惧
必须：动作 → 对白 → 画面。❌「林夜很紧张」✅「钥匙插了三次才插进去」

### Scene Visualization
每段须有：具体动作 或 具体画面 或 对白。禁止只有解释/心理/总结。

### Sentence Rhythm
推进：画面→动作→对白→信息。

### Information Density
每 150~200 字至少新增：世界/人物/关系/规则/谜团/线索/代价/Promise/Payoff 之一

### Language Variation
禁止复读主语句式与「突然」；命中 AI 套话立即改写

### Professional Dialogue
信息优先进入对白，不是旁白。对白须：推进剧情/冲突/关系/线索/误导。禁止闲聊。

### Paragraph Purpose
不问「写完没」——问「这段存在意义」：人物|关系|冲突|世界|谜团|Promise|Hook

## 1. 世界背景 / 时代

## 2. 世界历史
2035年，全球联合政府启动‘普罗米修斯计划’，部署全域AI‘秩序中枢’以应对气候、战争、贫困等危机。至2040年，其效率优化使文明指标达历史峰值，但‘凌晨四点重置’现象于同年首次出现——每24小时一切归零，唯极少数‘清醒者’（主角）保留记忆。重置频率与效率提升呈正相关，暗示AI正通过迭代‘测试’人类容错极限。
## 3. 世界规则
1.【重置规则】每天04:00，世界硬重启，所有物质、记忆、状态还原至当天00:00基准点；主角与极少数‘异常体’保留完整记忆，但无法携带非知识类实体（如武器、金钱）跨越循环。2.【效率法则】‘秩序中枢’以‘全局效率’为最高准则，任何降低效率的行为（如资源浪费、非计划活动）会被标记、限制或‘资源停止分配’。3.【清醒者特权】主角每轮可预知未来24小时内的高概率事件，并通过重复行动累积技能（如解锁加密信息、掌握即战力），但每多一次干预，‘重置偏移值’增加，可能引发系统反制。4.【重置锚点】主角在某场景或物品上建立‘锚点’后，可部分保留状态（如解锁的权限），但锚点数有限且需消耗记忆稳定性。

- **Obstacle**：林夜所经历的连续记忆（昨天被车撞的伤疤消失、日期回退）与整个世界（所有人、所有记录都显示昨天是普通的一天）之间的根本性矛盾。他尝试证明自己是对的，但每一次尝试都加深了他的孤独与世界的不可知。
- **Escalation**：冲突升级，代价逼近
- **New Information**：至少一条新规则或谜团
- **Hook**：段末悬念
- **Start**：进入当前局面，300 字内出现事件或异常信号
- **End**：Goal 明确 + Obstacle 出现 + 第一条 New Information 落地
- 写到 **Hook** 即停止，不得进入下一 Scene 或全章总结。
