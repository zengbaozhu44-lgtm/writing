# 写作圣经 · 霓虹之下

> 本书**唯一**写作规则源。世界观见 `01_world_bible.md`，人物见 `03_characters/`。

## A. 叙事原则（驱动剧情）

1. **现实目标优先** — 每章 POV 必须有可验证的当下目标
2. **利益驱动** — 选择 = 短期收益 vs 长期代价
3. **信息收费** — 情报不免费，获取必有成本
4. **人物主动** — 禁止被动等待异常降临；观察→判定→动作
5. **世界不围主角转** — 后台势力并行推进（见 `state_board.md`）
6. **对话是博弈** — 每句暴露伤口或撕开伤口，禁止寒暄确认
7. **每章不可逆变化** — 章末至少一项：物理 / 信息 / 关系

## B. 文风原则（驱动句子）

1. **身体先行** — 场景以生理反应开头；每 100 字 ≥1 次具体生理反应
2. **感官优先** — 信息寄生在物件与五感上；独立背景段 ≤30 字
3. **意识滞后** — 身体先动，大脑后知；禁止「他想起/意识到/觉得/知道」
4. **异常反噬** — 能力使用即时付代价；异常不可驯化为「工具/钥匙/接口」
5. **限知第三人称** — 每章聚焦一个角色；内心独白 ≤2 句/章，以问号结尾
6. **硬切节奏** — 禁止「然后/接着/突然/之后/与此同时」
7. **章间寄生** — 下章开头携带上章未完成感官，前 300 字不出现角色名

## C. 结构比例

| 参数 | 值 |
|------|-----|
| 单章字数 | 3000 |
| 对话占比 | 30%–60% |
| 动作:对话:心理 | 7:2:1 |
| 段落（单线） | ≤300 字，每段至少一个爆点 |
| 视角 | 第三人称限知，每章一个 POV |

## D. 对话规则

- 每句须含身体证据（伤口、痕迹、异常状态）
- 回应须否认、掩饰或转移，禁止直接确认动机
- 沉默须携带重量（缩手、眨眼、呼吸变化）

## E. 结尾规则

结尾须为**活体动作**：正在变化、侵入或生长；双向性（角色反应 + 某物主动）。

三选一：危机突现 / 反转落地 / 关键抉择。

禁止：温柔收尾、铺垫收尾、「他知道/明白」、以信息或感受结束。

## F. 禁止清单

- [ ] 解释设定（世界观须通过戏剧动作呈现）
- [ ] 全员上帝视角（POV 只能依据 `info_matrix` 行动）
- [ ] 异常推动剧情（须由目标受阻触发）
- [ ] 连续 50 字无身体反应
- [ ] 心理戏超过全章 10%
- [ ] 纯铺垫 / 纯环境 / 纯复盘段落
- [ ] 结尾搜索「是钥匙/是接口/是坐标/是工具」— 出现即重写

## G. 因果链（强制）

```
现实目标 → 受阻 → 利益计算 → 博弈/交换 → 不可逆变化 → 局势改变 → 下一章目标
```

## H. 主题与基调

主题：记忆作为最后的抵抗形式——抵抗被无声消化。

基调：冷冽、潮湿、霓虹色。不是爽文，是泥泞里的韧性。追求读者深夜想起某个动作时脖子发麻。

全书 Objective：七人在秩维局与帷幕碾压下，各自救出至少一段不可替代的真实记忆；终局帷幕消化概率从 80% 降至约 40%。

## I. 平台参数

- 目标 200 章，番茄连载
- 每 5 章小爽点，每 10 章综合考验
- 连续高压超过 9 章须插喘息章（补角色关系，非推进主线）
