# 世界圣经 · 霓虹之下

> 只描述世界如何运行。禁止：剧情、当前状态、写作技巧。

## 1. 世界背景

双层都市结构。表层为 2020 年代现代都市（表界）：霓虹、便利店、地铁站、档案馆、秩维局外包体系。里层为「烬界」（里界）：锈蚀街道、念灵活动区、无语言的灰色空间、情感物质燃烧后的残渣「烬」。

二十年前「门事件」在帷幕上留下裂痕，念灵渗入表层，记忆筛选机制变得粗暴。城市运行在「遗忘即秩序」的逻辑上。

## 2. 超凡体系

- **情感是物质**：执念、愧疚、欲望有质量，可提取、储存、交易、销毁
- **烬**：情感物质燃烧后的残渣；觉醒者可见、可感知
- **念灵**：高浓度情感残留的具现化污染体
- **帷幕**：表界与里界之间的过滤器兼牢笼；规定可见、可记、可保留的人性边界
- **裂隙**：帷幕破损点，强烈情绪 + 附近有裂隙时，普通人可短暂瞥见里界

## 3. 能力体系

觉醒者能力本质是「贷款」——每次使用付侵蚀代价。侵蚀度 100% 则烬化。

常见能力类型（规则级，非角色当前数值）：
- **旧页/灰印**：记忆接口，读取、映射、感知异常
- **食烬**：吞噬他人记忆残渣
- **锚定**：强化记忆锚点，难以遗忘
- **回声**：捕捉残留声音
- **等价**：因果与信息的交换
- **倒影/流动**：模仿与存在态变异

能力不可无限升级；每次使用必有即时反噬（身体、记忆、感知）。

## 4. 势力体系

| 势力 | 一句话定位 |
|------|-----------|
| 秩维局 | 伪装成城市基础设施维护的政府机构，实际擦除异常 |
| 帷幕 | 结构性规则，非人格化敌人 |
| 守夜人 | 里界深层组织，与「深井」相关 |
| 衔尾蛇 | 试图撕裂帷幕的激进派系 |
| 归墟使者（门缝） | 帷幕另一端的外显，关键岔路口出现 |

详情见 `04_factions/`。

## 5. 社会规则

- 普通人生活在表界，对里界异常被系统性掩盖
- 瞥见里界者会被秩维局追踪并接受「心理干预」（记忆修剪）
- 记忆抹除后身体约轻 2.4 克（都市传说变体）
- 信息不免费；情报在黑市与秩维局内部均有定价

## 6. 资源体系

- **记忆**：可交易、可污染、可锚定、可抹除
- **烬 / 念灵残留**：觉醒者养料或污染源
- **因果链 / 档案碎片**：裴言等情报商的交易标的
- **帷幕稳定剂**：秩维局清洁剂配方成分

## 7. 经济体系

- 表界：正常都市经济 + 秩维局外包档案数字化等产业
- 里界/灰市：记忆碎片、安全屋地址、门禁卡、规避监控方法
- 信息定价逻辑：等价交换，无免费情报

## 8. 历史

- **2016-09-27 门事件**：本地新闻三分钟口播后所有消息消失；帷幕裂痕起源
- 门事件前：秩维局为三人临时委员会
- 门事件后：记忆抹除产业化，秩维局扩张为城市基础设施维护伪装

## 10. 禁忌（世界铁律）

1. **情感是物质** — 不可当纯心理描写处理
2. **帷幕两端不能同时被同一人看见** — 切换付侵蚀代价
3. **记忆一旦抹除，无法通过任何已知手段完全恢复** — 不可逆
4. **禁止在正文中直接陈述以上铁律** — 须通过戏剧动作呈现
