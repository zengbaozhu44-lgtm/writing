# 第8章

抽屉还开着。他没有去关。

窗缝里进来的风带着水汽，是那种下了一整天、把墙皮都泡软的雨。楼下巷口的路灯亮着，光被雨切成一段一段，落在青石板上，又被脚步踩碎。他站在窗边没动，指腹压在窗框的木棱上，那里有一道旧裂纹，硌手。

身后有呼吸。

那人还坐在椅子上，没走。从推门到现在，椅子腿在原地磨过半寸，木地板留下一道浅白的痕。他刚才说“你自己看”，说完就坐下了，像这件事跟他无关，又像他必须等一个结果。

“看什么。”他开口，声音比预想的哑。喉咙里像卡着半口没咽下去的水。

“抽屉里的。”那人说，慢慢地，一个字一个字地放出来，“你自己拉开的那本。昨天的页码，今天还停在那儿。”

他没回头。窗外有人撑伞走过，伞面歪着，肩膀湿了半边。那人的影子从窗上的水痕里一晃而过，没了。

“我昨天没动过它。”

“我知道。”那人说，“所以我才坐这儿。”

他这才转过来。椅子上那人穿一件灰夹克，袖口磨得发亮，手搭在膝盖上，两只手指无意识地搓着什么——搓的是空气，什么也没有。屋里的灯没开，只有窗外那点路灯的光漏进来，把两个人的下半张脸都搁在暗处。

“老周走的时候，”他问，“你看见了？”

“看见了。”

“他没回头。”

“没回头。”那人重复了一遍，像在确认这件事的分量，“他走两步，停一下，又走。我没叫他。”

他没接话。老周那个停顿，他懂。停一下是在等，又走是知道等不来。这种事不用人说破，说破了反倒轻。

“那你来，是替谁来的。”

那人手指停了。停了大概两秒，才又动起来。

“没人让我来。”他说，“是我自己要来。抽屉里那本，我看过一页。就一页。”

屋里的空气沉下去半截。窗外的雨忽然大了一阵，砸在铁皮雨棚上，噼里啪啦，把两个人的话都盖住了一瞬。等雨声退回去，他才听见自己问：

“哪一页。”

“夹着东西的那页。”那人抬眼看他，眼神在暗里很稳，“你自己心里清楚。”

他清楚。那半张纸的边缘，昨夜被他指腹来回摸过，摸得起了毛。他没告诉任何人，连老周都没提。可现在这句话从别人嘴里出来，像有人伸手进他衣兜里，把他藏的东西掏出来，摆在桌上。

他走过去，一步，两步，到抽屉边上。那本册子还摊着，昨天的页码，边角被手指捻过，翘着。他没碰它，只是低头看。纸页上有一道压痕，是夹东西留下的。

“你翻的时候，”他问，没抬头，“看见什么了。”

“看见你没睡好。”那人说，“别的没看清。我把书合上了。”

他抬起头。两个人在暗里对着，谁也没先挪开眼。

楼下巷子里，又一把伞过去了。雨还在下。

他伸手，把抽屉推回去。推到底，木头磕出一声闷响。

“你走吧。”他说。

那人站起来。椅子腿又在地板上磨了一下，一道新痕，浅浅地叠在旧的旁边。他走到门口，手搭上门把，没急着拉。

“老周要是回来，”那人背对着他说，“别让他先看见那本。”

门轴响了一声，长音，然后合上。屋里只剩雨声，和他自己的呼吸。

他站在原地没动，数着门外的脚步，一步，两步，三步，越来越远，最后被雨吞掉。

数到第七步的时候，他才转身，重新看向那扇窗。

他转身的时候，膝盖先于意识动了一下，左腿僵了半秒才跟上。雨还在下，窗玻璃上爬满水痕，像有人从外面用指腹一遍遍抹，抹不干净。

他走到窗前，隔着那层水汽往外看。巷子里没有人。路灯的光被雨丝切成竖条，一段一段地明灭。刚才那脚步真的走远了，远到连回音都没留下。

抽屉还开着。他能感觉到它在背后张着口，像一句没说完的话。他没有回头，也没有去关。手指搭在窗框上，木头的漆已经翘起来，一碰就掉下一小片，粘在指腹上，凉的。

他把那片漆捻碎，才去看抽屉。

里面是一只铁皮盒子，边缘生了锈，盖子上有一道划痕，横的，很深。他没伸手。他知道盒子里有什么——不，他不知道自己算不算知道。手指离盒盖还有一寸，停住了。

雨声忽然小了一格，像谁把收音机的旋钮拧了一下。

门被敲响了。

三下，不重，间隔均匀。不是刚才那阵脚步的节奏。他数着——一，二——第三下已经落下。他的肩膀先绷起来，才慢慢放松。

他没有立刻去开。先看窗，再看抽屉，最后看门。门缝底下透进来一线走廊的灯，黄的，晃了一下，又稳了。

“谁？”他开口，喉咙里像塞了团湿棉花。

门外停了两秒。

“是我。”女人的声音，不高，尾音被雨压得很平，“灯亮着，我知道你在。”

他认得这个声音。手指从抽屉边缘收回来，指节上还留着木漆的干涩。他走过去，鞋底在地板上留下一串湿印——他自己都不知道什么时候踩进了水。

门开了一条缝。她站在走廊里，肩上搭着湿透的外套，头发贴在额角，手里拎着一个塑料袋，袋底往下滴水，在脚边积了一小滩。

“你这巷子，”她说，“排水又堵了。”

“我知道。”

“你知道你还站在窗边看。”

他没接话。让开半步，算是请她进来。她侧身挤过门缝，湿外套带进来一股雨腥气，混着她身上某种洗衣粉的味道。塑料袋放在鞋柜上，发出沉闷的一声。

“你那边，”他问，“怎么过来的。”

她拧着外套下摆，水顺着指缝落进地板缝里。“绕的。前面那条路封了，拉了线，有人守着。”

他看着她。她的眼睛下面有青，像好几天没睡。她没有看他，只是拧衣服。

“守着，”他重复了一遍，“守什么。”

“不知道。”她把外套搭在椅背上，水珠从袖口一滴一滴往下掉，“我路过的时候没敢停。线里面停着两辆车，没亮灯。”

巷子里的雨又大了。窗户被风顶了一下，咔地响。

她这才抬起眼，看向他身后——看向那个开着的抽屉。她的目光在铁皮盒子上停了一瞬，很快，快得像没看见。

“你还是没关。”她说。

“关了也一样。”

“一样什么？”

他张了张嘴，没说出来。喉咙里那团湿棉花又回来了。他走到桌边，拿起杯子，里面是昨夜剩的水，凉的，他喝了一口，咽下去的时候能感觉到它一路凉到胸口。

“你先坐。”他说。

她没坐。她走到窗前，站在他刚才站过的位置，往外看。玻璃上的水汽被她呼出的气又添了一层。她抬手，用指节在玻璃上写了个字，写完就散了，只剩一道水痕。

“我刚才在楼下，”她说，声音背对着他，闷闷的，“看见有人从你这条巷子出去。走得很快。”

他握着杯子的手收紧了。指节发白，杯壁上的水凝在指缝里。

“什么样的人。”

“没看清。”她转过身，“雨太大。就一个背影。可是——”

她顿住了。

“可是什么。”

“可是他走的方向，”她说，“是从你家门口。”

杯子里最后一点水晃了一下，撞在杯壁上，又落回去。窗外的雨声把巷子填满，一步，两步，三步——他忽然不确定，刚才数的那七步，到底是往外走的，还是往里来的。

抽屉还开着。这一次，他朝它走过去。

他走过去的时候没看路，肩膀蹭到门框，木头湿冷，像刚从水里捞出来。膝盖记住了那七步的节奏，走到第三步时顿了一下——是往里来的。他确定。七步，从巷口到门口，脚底踩在积水里的声音越来越近，然后停在门外。

抽屉里没有他以为的东西。

最上面是一叠纸，边角卷了，受潮发胀。他抽出来的时候纸页黏在一起，得用指甲去挑，挑开一道口子，露出下面一张照片。照片上两个人，一个是他，另一个被水汽泡得发白，五官糊成一团。他翻过来，背面有一行字，钢笔的，洇了大半，只认得最后两个字：速归。

他盯着那两个字，喉咙里滚了半圈，什么也没说出来。

门响了三下。

不是敲，是指节叩在木板上的那种，轻，但准。他抬头，雨声没停，门外的人也没再动。他站着，手里还捏着那张照片，纸的边缘嵌进指腹，压出一道白痕。

第四下。

他把照片放回抽屉，没关，走过去开门。门轴涩，拉到一半卡住，他用肩顶了一下才开。雨斜着扫进来，打在他脸上。门口站着一个人，撑一把黑伞，伞沿压得很低，只看得见下巴和淋湿的裤脚。

“你回来了。”那人说。声音不高，被雨吞掉一半。

他没答。雨水顺着门框往下淌，在门槛上积成一条线。

“我等了你三天。”那人把伞往上抬了一点，露出眼睛，“屋里灯亮着，我就知道你没走。”

“灯是我开的。”他说。这句话出来干得像砂纸。

“我知道。”那人往门里看了一眼，越过他肩膀，看的是那个开着的抽屉，“你翻过了。”

“翻了。”

“看明白了？”

他没回答。手指在门框上收紧，指甲刮过木刺，刮出一道细响。他想说没有，想说那行字认不全，想说照片上另一个人的脸被泡烂了——但话到嘴边，全咽回去。雨打在伞面上，啪，啪，啪。

“进来吧。”他说。

那人在门口站了两秒，收了伞，伞尖滴水，一路滴到屋里。他侧身让开，膝盖又僵了半秒。那人从他身边过，肩膀擦过他胸口，带着一股冷雨味，还有别的——很淡，像药，像铁锈。

“抽屉里的东西，”那人背对着他，停在桌前，“你没全拿出来。”

他心跳漏了一拍。他没说抽屉里还有别的东西。他自己都不知道。

“底下压着一把钥匙。”那人伸手，两根指头探进抽屉，翻了翻，捏出一枚铜的，举到灯下，“你不认得它了。”

“不认得。”他说。这是实话。

“那就对了。”那人把钥匙搁在桌上，发出很轻的一声，“认得的人，都回不来了。”

雨声忽然大起来，像有人把整条巷子的水都倒进了这间屋子。他站在门口，门还开着，风把雨吹进来，打湿了他的后背。他盯着桌上那把钥匙，铜绿斑驳，比照片更旧。他伸手，指尖碰到它，凉的，比雨还凉。

他握住了。

“你什么时候走？”那人问。

“不走。”他说。声音比刚才稳了些。

那人转过头看他，看了很久，然后笑了一下，不是笑，是嘴角动了一下。

“好。”那人说，“那我告诉你一件事——这屋子的灯，不是你开的。”

他手一紧，钥匙压在掌心里，硌得生疼。他张了张嘴，雨声灌进来，把那句话堵在喉咙里。窗外的巷子又传来脚步声，一步，两步，三步，往里来的，越来越近。

脚步声到门口停了。

他把钥匙攥得更紧，指节发白，血渗进掌纹。门板上全是水痕，一条一条往下爬。

那人没动。他能听见那人的呼吸，很轻，很稳，像在等什么先落地。

“这屋里的灯，”那人又说了一遍，声音低得几乎被雨吃掉，“不是你开的。”

他喉咙动了一下，想问那是谁开的，门板先响了一声。不重。像有人把肩膀靠上来，湿衣服蹭着木头。他膝盖一软，退半步，后腰撞上桌沿，碗在桌上跳了一下。

那人忽然伸手横在他面前，手背上一道旧疤，白得发亮。

“别出声。”那人嘴唇几乎没动。

门口那个影子没走。窸窸窣窣，像在摸门闩。他闻见一股味道，湿土混着铁锈，从门缝往里渗，越来越浓。

“灯是谁开的我不在乎，”那人偏过头看他，眼睛在暗里亮得吓人，“我在乎的是——这屋里有第三个人。你看见他了吗？”

他脑子里嗡地一响。第三个人。他刚才只数了两道呼吸，自己和那人的。他猛地转头去数——可屋里太暗了，桌角椅背的轮廓都糊成一团。他屏住气，听见自己心跳撞着耳膜，一下，两下。

门闩从外面被拨了一下。咔。

那人把他往旁边一拽。他踉跄半步，肩膀撞上墙，墙皮簌簌往下落。门开了一条缝，雨声猛地灌进来。有人站在门槛外面，浑身淌水，抬脚就要往里迈。
