# 第13章

那只手掌摊在桌面中央，掌纹里嵌着一道旧疤，从虎口斜拉到腕根，像条干涸的河床。主角盯着它，没有动。

雨还在下。窗棂上积了一层水汽，把外面巷子里的灯笼光晕染成模糊的一团。空气里混着潮湿木头和劣质烟草的气味，墙角那只铜炭盆已经凉了，灰烬里埋着几粒没烧透的炭核。桌面上摊开的掌心纹路很深，主角的目光顺着那道疤走了一遍，又走了一遍。

“你等了很久。”对面的人说。

声音不高，尾音被雨声吃掉了一半。主角抬起眼。那人坐在椅子里，背靠着椅背，姿势松弛得不太正常——像是一个人刻意做出来的松弛。右腿叠在左膝上，脚踝处露出一截灰白袜子和磨破的皮鞋边。左手还搭在扶手上，指节微微泛白。

“不算久。”主角说，“你进来之前，我在看那面墙。”

“墙上有东西？”

“水渍。形状像个人脸。”

那人笑了一声，很短，像咳嗽。“然后呢？”

“然后你进来了。”

沉默。雨声从窗缝里挤进来，一阵密一阵疏。那人把摊开的手掌收回，搁在膝盖上，五根手指依次屈起，又依次展开。像是在数什么，又像是在确认手指都还在。

主角注意到他的右手小指不太灵活，弯曲的时候比别的指头慢半拍。

“你刚才站起来的时候，”主角说，“绕开了地上那两块松动的砖。”

“嗯。”

“你第一次来的时候没绕。”

那人屈指的动作停了。雨声忽然大了一瞬，又落回去。铜炭盆里某粒炭核发出一声极细的碎裂响，像骨头在火里炸开。

“你记得挺清楚。”那人说。

“我记性一般。只是那两块砖的位置太怪了，铺在门槛内侧，稍微踩重一点就翘起来。你上次进来，右脚踩上去，砖翘了，你低头看了一眼，然后继续走。”

那人把叠着的腿放下来，两只脚平踩在地上。他的目光从主角脸上移开，落到桌面那道水渍上。水渍在灯下泛着暗黄色的边。

“所以呢？”

“所以你在掩饰什么。”主角说。声音很平，没什么起伏。“你上次不知道那两块砖会翘。这次你知道了，绕开了。中间这段时间，你来过。”

窗外有人跑过巷子，脚步声啪嗒啪嗒踩在积水里，很快远了。那人没有立刻接话。他伸手去够桌上的茶碗，碗底磕在木面上，发出一声闷响。茶早就凉透了，他端起来抿了一口，喉结动了一下。

“我来过。”他说。

“几次？”

“三次。”

“来做什么？”

那人把茶碗放回去，碗底和桌面之间夹着一小圈水痕，慢慢洇开。他看着那圈水痕，像在看某种只有他自己能读懂的东西。

“看一样东西。”他说，“你屋里那个柜子，最下面那层抽屉。我没打开过，但我量过它的尺寸。”

主角的脊背贴着椅背，木头很硬，硌着肩胛骨。他没有回头去看那个柜子。他知道它在哪儿，在床尾靠墙的位置，最下面那层抽屉上了锁，钥匙在他贴身的衣兜里。那个抽屉里放着什么，他也很清楚。

“你量它做什么？”

“有人托我量。”那人说，终于抬起眼，目光很稳，落在主角脸上，“那人说，抽屉里的东西，值一条命。我想知道，是你的命，还是别人的。”

雨声忽然变得很远。主角听见自己的呼吸，很轻，很稳，从鼻腔里出来，带着一点凉意。他没有说话。那人也没有催。两人隔着一张桌面的距离，像隔着一整条巷子那么远。

铜炭盆里的灰烬塌下去一块，发出一声细响。

那人把手掌翻过来，又翻回去，掌心朝上停住，像是把一件东西摊开给谁看。疤在炭火余光里泛着一点暗红。

“你刚才站起来的时候，绕开了地上那两块松动的砖。”他说，“左一步大，右一步收。走得挺准。”

主角的拇指在膝盖的粗布上蹭了一下。布磨得起毛，蹭上去有点涩。

“砖松了，谁都绕着走。”

“下雨天，满地都是松砖。”那人把掌心按在桌面上，慢慢压平，“可你绕得像是量过。一块，两块，不多不少，两只脚都落在实处。”

主角没说话。他听见檐口的雨砸在青石上，一滴比一滴稀。炭盆里那股塌下去的灰，凉气贴着小腿往上爬。

“这说明有个人事先数给你听。”那人说，“或者你自己数过。数过的东西，走起来才省力气——也才藏得下人。”

“你倒是喜欢看别人走路。”主角说。

“我更喜欢看人怎么躲。”

主角的小指在桌沿底下弯了弯，比别的指头慢半拍才贴住掌心。那只手他熟，熟到闭着眼也知道哪根指头不听话。

“巷子短。”他说。

“短。”那人点头，笑意在嘴角停了一下就散了，“可你今天比昨天走得慢。慢不在腿上。”

雨声忽然又回来了，密密地敲在瓦上。主角伸手去够桌上那只茶碗，碗沿缺了个口，拇指正好卡进去。他没喝，就这么捧着，凉意从豁口渗进来，一直渗到指根。

“你要的东西，不在砖底下。”他说。

那人把手收回去，收得极慢，像卷一张受潮的旧纸。收拢时蹭过桌面，把刚才压出的一小片湿痕抹淡了。

“我知道不在砖底下。”他说，“可我得先看清，你走路的时候心里是不是还留着位置。留着位置，才谈得上往哪儿挪。”

主角捧着碗，指节泛白。

“你想挪什么？”

“挪你。”那人抬眼，“或者，被你挪开。”

檐外有人踩水跑过，哗啦一声，远了。主角数到七，把碗放下。碗底磕在桌面上，脆的一声，缺口对着缺口。

“巷子里的砖，我自己数的。”他说，“数了三年。”

碗底那声脆响在木桌上滚了半圈，像一颗石子落进深井。主角看着自己的左手，小指还搭在碗沿上，弯得比别的指头慢半拍——他数过，从食指到小指，依次是四拍、三拍、两拍、一拍。那只小指总在最后一拍上卡住。

“三年。”那人重复了一遍，声音像在称一块湿木头。

“砖窑没拆之前，”主角说，“巷口到巷尾，我走过一千零九十五遍。每一块砖都认识我的鞋底。”

“你刚才绕开了那两块。”

“松动的砖踩上去会响。”

“响了会怎样？”

主角没回答。檐外又有脚步踩过水洼，这次是两个人，啪嗒啪嗒，往巷口去了。他等那声音彻底消失，才把左手从碗沿上收回来，平放在桌面上。小指还是慢半拍，像一根被线拽着的木偶指头。

“你刚才说，”那人开口，“你数了三年。”

“三年。”

“从哪年开始数的？”

主角的喉咙动了一下。他的视线从碗沿移向那人的手，那只手正按在桌角，掌心朝下。疤从虎口延伸到腕骨，在灯下像一道干涸的河床。

“那一年巷子里死了两个人。”主角说。

“哪两个人。”

“你不认识。”

“你怎么知道我不认识？”

主角的指节在桌面上收拢，指腹抵着木纹，来回蹭了两下。那只小指还是没跟上，弯了一半就停住，像被什么东西卡住了。

“因为是我埋的。”他说。

那人没有动。灯焰跳了一下，影子在墙上晃了晃。

“你埋的。”那人重复，语气里听不出惊讶。

“砖窑后面有块空地，土是松的。”

“你一个人？”

“一个人。”

“挖了多久。”

“一夜。”主角说，“天亮之前填回去的。”

他感觉到自己的左手在桌下轻轻抖了一下，小指碰到掌心。他攥住它，用其余四根指头。

那人把手从桌角收回去，搁在膝盖上。他低头看着自己的手，翻过来，又翻回去。疤在光里泛着暗红，像一道刚结痂的口子。

“你数砖，”那人说，“我数人。”

“什么意思。”

“你数这条巷子有多少块砖。我数这条巷子里走过多少人。”

主角的呼吸停了一拍。他听见檐水落进石臼的声音，一下，两下，三下。

“你数了几年。”

“你数三年。我数了十七年。”那人把手掌按在桌面上，掌心那道疤正对着碗底的缺口，“你埋的那两个人，我认识。”

主角没有说话。他感觉到桌下的那只手终于松开了，小指慢慢弯下去，扣住掌心，像一枚锈死的锁终于合上了。

雨还在下。檐角的水滴在青石板上，一下，一下，间隔长得让人以为停了。

那人的手没有收回去。掌心那道疤横过掌纹，像有人用刀在他手里画了条路。

“你认识。”主角终于开口。声音比他预想的干，“他们叫什么。”

那人看着他，像在等这句话等了很久，又像根本没打算答。他把碗底那块缺口转了个方向，正对着主角。

“你埋的时候，给他们盖了脸没有。”

主角的喉咙动了一下。他记得土是湿的，记得铁锹柄上缠的布条磨破了手，记得一锹，两锹，三锹——但脸。他不记得脸。他只记得自己没敢看。

“没盖。”他说。

那人点头，像是印证了什么。“那就对了。”他往椅背上一靠，木椅腿在潮气里吱的一声，“没盖脸的，三年后会自己回来找你。这是规矩。”

主角的手指在桌下收紧。小指还是慢，扣进掌心的时候像被什么绊了一下。

“什么规矩。”

“你埋人的时候没人教你？”

“没人教。”

那人沉默了一会儿。雨声填进来，把两个人之间那点空隙灌满。他忽然伸手，把主角面前那只碗翻过来扣在桌上。碗底朝上，缺口朝西。

“我不是来教你规矩的。”他说，“我是来告诉你，你埋的那两个人，有一个没死。”

主角坐着没动。他听见自己的心跳在耳朵后面，一下，一下，比雨点沉。

“哪个。”

“左边那个。”那人说，“右边那个是真死了。左边那个，你盖土的时候，他还有气。”

主角的胃往上顶了一下。他想起那天的土，想起铲下去的时候有一瞬觉得土是软的，比别处软。他当时以为是雨泡的。

“你怎么知道。”

那人把手收回去，拢进袖子里。“因为是我把他挖出来的。”

他站起来。椅子往后蹭了半尺，声音刮在木地板上。他走到门口，手搭在门框上，回头看了主角一眼。

“他这些年一直在数。数你埋了他多少锹。”

门开了。雨声一下子涌进来，白茫茫堵在门口。那人的背影陷进去，很快只剩一个轮廓。

主角还坐着。桌上那只碗翻扣着，缺口朝西。他伸手想去把它翻回来，指尖碰到碗沿的时候停住了。

他忽然发现自己想不起来——那天，他到底铲了多少锹。

外面，雨声里混进一个脚步声。很轻，一下，一下，间隔长得让人以为停了。正朝这边来。
